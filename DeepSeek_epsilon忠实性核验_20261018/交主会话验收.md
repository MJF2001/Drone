## 5. 核心决策保留的证据（这是本轮要证明的重点）

| 原机制 | 保留证据 |
|---|---|
| T^0 为单格、最粗层为四格剖分、逐层细分直到 `n/2<2` 或 `n'-1<2` | 六张图的 L 与每层块数、块尺寸与手算一致；每层通过"不交且覆盖"断言；无一层含整图 |
| 邻域 7×7（L0）、3×3（L≥1，按粗格计） | `test_level0_is_seven_by_seven`、`test_level_neighbourhood_is_three_by_three_cells`；长条图上旧 padding 公式给出 4/6 个块而论文为 3/4 |
| Eq. (2)/(3) 势场 | 值级测试；增量更新与整层重算逐层相等 |
| Algorithm 1 全部分支 | 轨迹里 L5、L6、L8、L10、L16 均出现；旧/transit 臂 L5/L6 恒 0 |
| 逐级逃逸与 `I(·)` 随机取未探索细格 | 房间图逃逸 1 次，层号 ≥1，记录所取粗格与候选数 |
| 只在作业时置 E（WT） | task 臂作业数 = 覆盖目标数，Corollary 1（每格一次）成立 |
| 有限终止（Theorem 1） | 20 次轨迹全部由算法自身 FN 终止，人工 `state_cycle`/步数上限未触发 |

## 6. 必须说清楚的边界

1. **不是性能结论**。本轮没有在 10 张开发图上跑，也没有与 P2 比较；
   旧版 300 项结果不改、不重算，但**不能再当作"ε* 原文机制"的成绩**。
2. **不是轨迹逐步等同**。四邻接单位步、每步重算、只对 Q 给正势、返航段都是适配，
   原文的连续运动/连续时间反馈没有被复现。
3. **两处仍是适配而非原文**：式 (5) 的距离用网格步数、转角成本取值 1.0（原文未给数值）；
   直接可达用超覆盖判据（比原文更严）。
4. **一处明确未实现**：Remark 3.2 的 flood fill——本模型地图已发布、不存在"障碍内部未探测"，
   实现它只会空转。
5. **没有改**：旧核心、旧适配器、共享连接器、共享审计器、旧交付清单。
