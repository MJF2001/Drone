# C* 可行严格复现的实现约定

本文档对应 `cstar_strict`，固定复现目标为原论文 C* 的单机器人、二维、未知静态环境核心算法。论文版本锁定为 arXiv `2505.13782v3`（2026-03-06）。实现依据论文 Algorithm 1–4 和 III-B，未取得作者原始实现及完整实验配置。以下区分原文规则、离散实现约定与必要的执行状态保护，不声称与作者程序逐行等价。

## 复现边界

实现使用整数采样格点，采样分辨率 `w=1`。每个格点代表一个 lap 上的候选 waypoint；实际运动在相邻节点之间用直线段完成。环境由自由方格的并集表示，障碍物是其补集。传感器只向规划器返回有限半径、带遮挡的已观测单元；规划器不读取真值地图。

覆盖评估独立于规划器：以半径 `r_c` 的圆盘沿规划轨迹扫掠，用子格采样计算面积覆盖率，同时给出保守的 certified lower bound。对每个子格使用“中心到轨迹的距离 + 子格半对角线 ≤ r_c”作为充分条件，100% 下界意味着所有子格均获证（浮点容差 1e-10）。论文定理对内部自由空间给出完整覆盖结论，对障碍边界附有 resolution completeness 限定；不能把离散格点访问率等同于连续面积覆盖。

默认审计为 `w=1, r_c=0.75`。其他半径必须重新审计，特别是满足 `w≤2r_c` 并不自动保证方格外边界及角点全部覆盖。碰撞检查针对点机器人中心线，覆盖圆盘允许超出自由区；没有隐含有限机体半径或三维安全保证。

## 逐项对应

| 原文机制 | 实现位置 | 约定 |
|---|---|---|
| III-B1 Navigation, Discovery and Coverage | `geometry.World`, `planner.CStar.navigate` | 在到达 waypoint 前沿路径连续感知；以 `w/2` 间隔采样传感器位姿。 |
| III-B2 sampling front | `geometry.KnownMap`, `rcg.RCG.sample_front` | 维护已知自由格、累计采样点和节点 Op/Cl；新发现自由格中满足 frontier 条件的格成为节点。起点限定为整数格点，整数格是与 `p0` 对齐的 lap 相位。覆盖面积另由轨迹审计。 |
| III-B3 expansion | `rcg.RCG.expand` | 同一竖直 lap 的相邻节点连接；相邻 lap 在 `sqrt(2)w` 邻域内连接；所有边都经过已知自由空间检查。新节点会拆分原有的同 lap 长边。 |
| III-B3 pruning | `rcg.RCG.essential`, `rcg.RCG.prune` | 按 Def. III.8/9 判断未知邻接、lap 端点及端点过渡。额外保护当前节点和未完成 link/TSP 锚点；非必要节点移除时合并同 lap 两边，删除其跨 lap 边。全图分类，不继承原文局部剪枝复杂度。 |
| Algorithm 1 | `planner.CStar.select_goal` | 固定坐标系按 Left → Up → Down → Right 选择 Open 邻居；同组用可复现随机数选择。死端从 retreat nodes 中按 RCG A* 路径长度选择。 |
| Algorithm 2 | `rcg.RCG.update_state` | 按正文与 Lemma IV.6 解释：只有上下两个垂直节点都 Open 时保留当前节点 Open，否则置 Closed；缺失邻居视为不满足 Open 条件。向左切换且存在距离大于 `w` 的 Open 垂直区间时插入 link node。 |
| retreat nodes | `planner.CStar.refresh_retreat` | 沿连续轨迹更新距离不超过 `sqrt(2)w` 的 Open 节点；新发现节点回看整条已走轨迹，避免在“节点生成晚于经过轨迹”时丢失 retreat 状态。 |
| coverage hole | `planner.CStar.detect_holes` | 从当前节点相邻 Open 节点 flood-fill，遇到 Closed 节点或目标节点停止；若连通分量的节点都不接触未知空间，则认定为 hole。 |
| Algorithm 3 | `planner.CStar.densify`, `optimize_tsp` | 在 hole 的同 lap 段按 `w` 加密；边代价为 RCG 上的 A* 最短路径；最近邻生成初解，再用 2-opt。固定起点、目标终点和自由终点分别处理。 |
| Algorithm 4 | `planner.CStar.run` | 感知 → 采样 → 扩展 → 剪枝 → 选点/回退 → 更新状态 → 空洞检测 → TSP → 继续。每轮保存 RCG 快照。 |

## 原文歧义的处理

原文 Algorithm 2 的伪代码只在上下节点之一为 Closed 时关闭当前节点，但紧接的正文和 Lemma IV.6 说明“除上下两个节点都 Open 外均关闭”。实现采用后者，因为它能处理 lap 端点和缺失邻居。

原文 Algorithm 2 没写出 link node 的“垂直 Open 邻居距离必须大于 `w`”条件；正文和复杂度引理写出了该条件。距离大于 `w` 时在偏移 `w` 处插入节点；已有邻居恰好距离 `w` 时，不新增节点，但将其标记为 link 锚点。这一实现补充用于防止全图剪枝把未完成航段的已有入口删除；不改变 Algorithm 1 的选点顺序。新建与复用锚点分别理解，`link_count` 仅统计新建数量。

原文 Algorithm 3 对自由终点 TSP 使用 dummy node，但给出的有限边设置在某些实例下无法形成有限 Hamilton 回路。实现直接求固定起点、自由终点路径，这与其执行语义一致，并在 TSP 事件中记录 `case=3`。

原文 III-A 声称 waypoint 不重复，但 Algorithm 2 的保留 Open 状态、retreat 回退以及 TSP 闭环都会产生合理的轨迹重访。实现分别记录图节点状态和真实轨迹，允许运动层面的重访。

## 明确的离散实现选择

- 感知射线和运动检查都按闭方格几何禁止切角。同距离进入的多个格一起判定遮挡，若存在阻挡，只公开阻挡格，不因坐标排序提前公开遮挡后的自由格。静态地图若收到矛盾占据值，直接报错。
- 感知是沿轨迹以不大于 `w/2` 的间隔离散采样，不是精确连续传感器仿真。图像、姿态噪声不在复现范围内。
- 端点过渡边的“靠近障碍/未知区”使用 5 个中间采样位置的平均净空，平局按长度和坐标消解；原文未给出完整数值设置。
- retreat 和 TSP 的 A* 均搜索当时已知 RCG。TSP 完全图是该图的最短路度量闭包，实际连接可经过 hole 外的已知节点；论文未明确 TSP 的 A* 搜索域，本实现不声称 hole 内受限最短路，也不使用真值地图或隐藏的栅格路径回退。
- 最近邻和 2-opt 是启发式，既不保证 TSP 全局最优，也不保证开启补洞后整条覆盖路径总优于关闭版。固定起点/终点受到保护，自由终点允许改变。
- TSP 完成只关闭其目标节点；若入口仍承担外部 Open 航段则保留入口，实际出口留待下一轮 Algorithm 2 处理。途经其他节点不等于它们的相邻航段已完成。
- `validate` 检查无自环、双向边、已知空间可行性与连通性，不构成对原文平面性、最小充分性或所有输入完备性的重新证明。

## 本轮修复与可重复验证

1. 原 `radius=2, clutter seed=1, TSP on` 在 `(4,8)` 生成孤立节点：修复射线角点同时命中的遮挡顺序，未采用删除孤点来掩盖问题。
2. 短传感半径暴露已有 link 入口被剪掉的漏扫：复用并保护距离 `w` 的已有节点。
3. 仅两个节点、固定不同终点的 TSP 原来遗漏终点：修复追加终点的条件。
4. 信息时序测试逐段重放观测增量，仅用出发时已公开自由格检查运动，替代使用最终地图的无效证明。

`python -m unittest -v` 运行定向回归；`python validate_suite.py` 运行多半径验证并保存源码 SHA-256、参数和逐例审计。`run.py --require-full-coverage` 可将面积证书不满 100% 设为失败；默认也会对内部漏扫、碰撞及异常终止返回非零退出码。`graph_exhausted` 单独只表示图节点耗尽。
