## 2. 我们真正需要的问题形态（与作者默认离线 TSP 不同）

我们要的是：

> 从**当前真实位置** `current` 出发，访问**全部当前待完成目标格** `Q`
> （经过即覆盖，四邻接，单位步长），最后**结束在基地** `base`。
> 起点与终点都固定，长度 = 自由图上的 BFS 最短路距离之和。

这是一个**固定起终点的开放路径**（Hamiltonian path），不是作者默认的闭合 TSP 回路。
原文 TRACE 用 LKH 做什么形态，正文没有逐项写清，**不能默认与我们一致**。

可行的编码（按推荐顺序）：

| 方案 | 做法 | 风险 |
|---|---|---|
| A. `PROBLEM_TYPE = HPP` | 节点 = {current, base} ∪ Q；`EDGE_WEIGHT_TYPE = EXPLICIT` 全矩阵；LKH 直接求固定端点的 Hamilton 路径 | 需确认 HPP 是否支持两端都固定（部分版本只固定一端） |
| B. `PROBLEM_TYPE = CATSPP` | 带前后序约束的非对称路径问题；用虚拟节点把 open path 变 TSP | 参数复杂，需实测确认等价性 |
| C. TSP + 虚拟节点 + 大 M 边 | 加一个零权虚拟节点，`base→dummy` 与 `dummy→current` 为 0 | **不推荐**：大 M 会掩盖不可达；一旦矩阵不满足三角不等式，LKH 的候选集构造会退化 |
| D. 闭合回路后截断 | 求回路再在 `base` 处截断 | **禁止**：会得到不是最优开放路径的结果，却容易被误报成"最优" |

推荐先用 **A**，并在最小实例（≤10 个目标）上用 `tests/exact_reference.py` 的精确
`(position, covered-mask)` 搜索**独立核对**最优值，确认编码等价后再放大。

## 3. 距离矩阵：整数、闭包、不可达

1. **必须是整数**。本项目所有距离是四邻接 BFS 步数，天然整数，不需要 `SCALE`。
2. **闭包预处理**：节点数 `k = |Q| + 2`，需要对 `current` 与每个目标各做一次 BFS 得到行，
   再与 `base` 的行拼成 `k×k` 矩阵。复杂度 `O(k·N)`（N = 自由格数）。
   若复用冻结 `UnifiedGeometry` 的批量 BFS 行缓存，实际只需 **k 次 BFS**，
   但**必须计入端到端时间**，不能只报求解器秒数。
3. **不可达**：先用 `problem.reachability()` 独立判定。
   - 任一目标不可达 → `environment_infeasible`，**不**用大 M 塞进矩阵；
   - 基地不可达 → 同上；
   - 只要全部可达，四邻接图是连通的（同一连通分量），矩阵有限。
4. **对称性**：无向图 → 矩阵对称。若某版本要求非对称，仍可直接用对称矩阵。
5. **零距离对角**：`d(i,i)=0`，非对角必须 ≥ 1；目标格互不相同时距离 ≥ 1。

## 4. 随机种子与终止配置（必须预先固定并披露）

LKH 的参数文件需要显式写出并使用：

| 参数 | 拟用值 | 说明 |
|---|---|---|
| `SEED` | 与 `PlanRequest.seed` 绑定，逐次记录 | 保证可复现 |
| `RUNS` | 固定（例如 1） | 多次运行会混入随机性，必须单列 |
| `MAX_TRIALS` | 固定上限 | 与"自然收敛"区分 |
| `TIME_LIMIT` | **与软预算一致**，触发时单列为截断 | 不能把超时结果当自然结束 |
| `MOVE_TYPE` / `PATCHING_C` 等 | 保持默认并记录 | 改默认参数属于调参，需另立版本 |
| `OPTIMUM` | **不设** | 设了会让 LKH 因"达到已知最优"提前停止（若真有最优值，说明问题被事先解出） |

## 5. 必须计入的成本（端到端）

1. 读取输入、构几何；
2. **距离闭包**：k 次 BFS（可复用批量行缓存，但成本照算）；
3. 矩阵落盘/参数文件生成；
4. **进程启动**开销（外部可执行文件，通常 10 ms 量级，必须实测而非估算）；
5. LKH 求解本身；
6. 读回路径、**展开成逐格路线**（TSP 只给目标顺序，实际路线还要拼接 BFS 路径、
   统计途经覆盖）；
7. 返回前的合法检查（由我们的独立审计另算，不计入方法时间，但要单列）。

## 6. 不能声称的

- LKH **不是**最优性证书：它是启发式，即使拿到已知最优也只是"与该值相同"；
- 原作者"精确求解"的说法不能转述为本项目的精确性结论（见精读 §9.3）；
- 即使拿到格级 TSP 最优值，也必须先对齐**访问规则、起终点、运动与覆盖足迹**，
  才能与真实覆盖路线比较；本项目"经过即覆盖"会让 TSP 目标顺序的最优性
  与实际覆盖步数的关系更紧，但仍然不是同一个问题的证明；
- 不能把 LKH 当"强参照所以其他方法差"的理由；它只是离线高质量参照。
