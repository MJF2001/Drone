## 2. 实际采集时序：本轮最关键的适配

原文把"移动（mv）"和"作业（tk）"分开：只有 WT 状态里 `ts=Complete` 才把该格的势置 0。
本项目的模型规定"经过目标格即完成该格覆盖"，而且账本必须反映真实经过。
两者不能同时成立，因此实现里把**物理覆盖**与**内部 MAPS 更新**分开：

- `credit="transit"`（默认，交付口径）：每走一格，若该格是待完成目标就立即记入账本并更新势。
  后果：进入 CP0 时 `λ` 的势已经是 0，`λ ∈ D⁰` 永不成立，
  **Alg.1 行 6 的"就地作业"分支在默认时序下不会触发**（`tests/test_epsilon_handtrace.py`
  断言 `trace.tasks == 0`）。原文"在未探索格中间停下作业"的行为因此消失。
- `credit="waypoint"`（**仅诊断**）：模拟原文的移动/作业分离，只在实际作业时更新 MAPS，
  物理覆盖仍按经过记账供审计。该模式用于展示原分支，`m17/toy` 上 `tasks > 0`。
  它**不得**作为本轮 ε* 的结果上报。

这项适配改变了决策轨迹：条带更连续，但不再有"中途停采"。原文截图里的作业停顿无法对比。

## 3. 损失清单（逐条）

1. **"allowed cell"缩小为目标格**。原文要求覆盖区域内每个 allowed ε-格都有正势；
   本项目只需覆盖已发布目标，因此自由非目标格势为 0（可通行、不作业）。
   若把本项目目标理解为原文的 allowed 区，两者才等价；报告不能默认成立。
2. **无障碍缓冲环 F**。原文用 F 处理惯性/转弯半径；本项目无惯性、半径为 0，
   默认 `forbidden_ring=0`。参数保留，设为 >0 时按切比雪夫距离生成缓冲。
3. **转弯代价不启用**。式(5) 的 `CTu` 默认 0：本项目的首要指标是步数，
   不能让某个方法独享转弯罚权（执行稿 §6 的要求）。
   若要研究转弯，必须对所有方法统一。
4. **Bug2 → 共同连接器**。原因：最终动作必须四邻接可执行，而 Bug2 是连续几何。
   影响：高层逃逸的绕行几何与原稿不同；代价仍是最短四邻接步数，因此不会"更短"，
   但可能比 Bug2 的贴障路径更直。
5. **候选邻域与动作分离**。N⁰ 默认 7×7、N^ℓ 默认 3×3 个粗格（原文实验取值），
   是**候选**集合；真正执行的是朝选中候选走一步四邻接。两者不混同，
   也不把候选压缩成四邻域。
6. **层级不等深**。递归对半在奇数尺寸下会产生不等深分支（例如 7→4+3，4 还会再分）。
   本实现的层号取 `L − depth`，某分支提前停止时，该分支在更细层用自身作代表。
   原文默认各层是完整划分，这一点是实现约定的偏差。
7. **端点为基地**。原文在 FN 处原地停机；本项目必须返回基地，`return_to_base`
   用共同连接器补最后一段，并计入步数。
8. **只公开当前地图**。瓦片化的包围盒只取当前 `free ∪ published_targets` 的范围，
   不使用任何未来扩展信息；事件后重建层次，并把**真实账本**注入，历史不重置。
9. **不对噪声/定位误差建模**。原文有 AWGN 实验；本项目没有传感器模型，不引用其覆盖率曲线。
10. **完备性不继承**。原文 Theorem 1 与 Remark 3.4 是在其连续模型与"作业即覆盖"时序下证明的；
    本适配改了时序、邻域与连接器，因此**不声称**本实现具有原文的完备性保证。
    实际保证只有：跑完所有层仍无正势时报告 FN；若此时账本仍有待完成格，
    适配器不会宣称完成（`coverage_incomplete`）。

## 4. 手算可追踪的例子

`tests/test_epsilon_handtrace.py` 在 4×2 图上给出可手算的全部数值：

```
包围盒 x0=0, x1=3, y0=0, y1=1
B(x) = x1 - x + 1 = 4, 3, 2, 1
x 轴 n=4 → 2+2；y 轴 n=2 → n/2=1 < 2 停 → 根只沿 x 分一次
L = 1：根在 1 层，两个 2×2 块在 0 层
式(2)：全未探索 → E⁰ = B(x)
式(3)：pU=1，mean B = 2.5 → E¹ = 2.5
起始格在 transit 模式下立即置 0 → D⁰ 不含 (0,0)
第 1 次 Alg.1：D⁰ 其余 7 格，argmax E⁰ = 4 在 (0,1) → wp={(0,1)}
第 2 次 Alg.1：在 (0,1)，D⁰ = x≥1 的 6 格，argmax E⁰ = 3，等势 {(1,0),(1,1)}
```

决策轨迹与每一层的使用情况写入 `artifacts/epsilon_trace/toy_4x2_decisions.json`。
