## 当前研究状态

二维单机、四邻接等长移动、正下方单格采集。障碍禁飞并遮挡目标，未完成遮挡目标暂缓，不计完成。当前仅算法研究，不包含视觉、飞控或实测能耗系统。

截至2026-10-19，PPCPP作为首要改进候选，OARP独立运行版作为重要对照，P2与TREE保留为已有基线。下一步核对PPCPP机制与独立运行表现，完成TRACE、C*、CAP的复现和同条件比较。底层算法确定后，再比较局部与整体重规划；局部具有综合优势时再研究范围。尚未确认最终论文主算法或创新点，不把场景适配称为完整原版复现。

最新OARP独立复测已去掉额外全局贪心与旧路线候选：相同10个开发状态、两个种子、三档预算共60次。1秒档18/20及时合法完成，20秒和120秒档均20/20；后两档各20次总步数均10658，合计公共规划耗时5.915秒/5.968秒。当前PPCPP已有成绩仍包含框架候选，需独立复测后再作核心比较。以上属于开发数据，不能证明普遍领先。
