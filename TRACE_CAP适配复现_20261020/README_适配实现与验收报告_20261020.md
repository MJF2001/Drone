# TRACE 与 CAP：公开地图重启适配实现及首轮正确性验收

日期：2026-10-20。版本标签：TRACE_PUBLIC_RESTART_v0.1、CAP_PUBLIC_RESTART_v0.1。

## 1. 结论先行

两套独立实现已落地，并通过本轮有限正确性检查。可封存为**声明适配边界的开发候选快照**；不能称完整原论文复现、作者实现、正式性能排名或主算法。

| 检查层 | 数量及结果 | 能证明什么 |
|---|---|---|
| 单元机制 | 27 项通过 | 分区、树/图、端点、历史/遮挡账本等已测机制 |
| 历史微型用例 | 26 输入 × 2 算法 × 2 种子 = 104 次；92 完成、4 资源拒绝、8 不连通拒绝；104 份独立审计通过 | 23 个可完成输入和 3 个负例符合预期，不把负例当成功路线 |
| 截止专项 | TRACE 17 阶段、CAP 16 阶段；各测截止前/恰好截止/截止后，共 99 次通过 | 33 次完成、66 次截止拒绝；检查点命中已记录，不是硬实时证明 |
| 道路正确性 | 20 个既有公开状态 × 2 算法 × 2 种子 = 80 次；80 条合法完整路线，80 份审计通过 | 本轮道路输入下均完成剩余覆盖和返航，满足步数上限和 20 秒核心截止 |
| 保存结果再审 | 微型 104 + 道路 80 + 截止 99 = 283 份 | 从原始输出只读复核；不重复计为新增求解 |

两个种子的处理是确定性重复，语义输出逐项一致，**不是独立随机样本，也不是 40 张不同道路图**。道路为 10 个控制状态、10 个事件状态；每算法小/中/大分别 12/12/16 次求解。道路核心计时最大 TRACE 5.485496 秒、CAP 8.459143 秒，仅描述本批运行，不作速度胜负结论。两个最大路线值均为 1389 步，也不据此认定质量相等或谁更优。

没有性能排名、参数追优、初始规划扩展或留出测试；没有调用 P2/MST/C*/PPCPP 补全。旧冻结源码、旧失败结果和旧实验目录未作回填。

## 3. 保持哪些算法区别

| 层次 | TRACE 当前实现 | CAP 当前实现 |
|---|---|---|
| 区域组织 | 保留父子分裂历史的树；格子到叶节点索引 | 覆盖引导图，区域节点之间采用最短路度量的完整图，不是树 |
| 区域更新 | 只查受变化格影响的叶；残余断开产生孩子 | 覆盖后更新残余；分裂替换节点及全局重排函数另有机制测试 |
| 全局顺序 | 完成槽位移除；分裂只替换原槽，未受影响区域相对次序保留 | NN + 2-opt 全局区域排序；有探索节点时最远探索节点固定为终点 |
| 已探索局部覆盖 | 固定当前位置起点；下一地区中心作虚拟终点，末区自由终点 | 固定当前位置起点、固定目标格终点的 NN + 2-opt |
| 探索相关机制 | 左 lap 优先、符号延迟标记、边界脱困等函数分别测试 | 固定全局方向 Left/Up/Down/Right、探索状态及远端规则分别测试 |

已探索区域的覆盖不是任意“扫完后再由全局算法补漏”。每个局部 TSP 必须表示全部该区未完成采集格，执行逐段合法最短连接，覆盖及返航都独立核实。NN 与 2-opt 是启发式，不声称求得 TSP 全局最优。

## 4. 必须公开的适配选择

1. **当前地图全部公开，不人为造未知区。** 道路求解只走已探索分支。探索函数的单元/结构测试不等于完成原生未知环境的在线控制器；没有传感器、形态学闭运算、运动学或跨地图事件流仿真。
2. **每个事件状态从公开快照重启。** 输入包含当前位置、既有完成集合和当前地图；不推测事件发生前的树/图，不预读未来事件，也不声称支持保留原始在线树跨事件增添新区域。本轮树的主要分裂发生在用历史覆盖初始化时，不能拿它验证未知环境下持续分裂的收益。
3. **可飞域 F 与采集任务域 T 分离。** 覆盖过或非目标的可飞格可以作通路，不会增加新采集责任。历史已完成格即使新被阻挡，仍记为已完成但不能飞；尚未完成的被挡目标暂缓，不能记完成。每次只采集脚下一格，四邻接等长移动。
4. **距离/连接适配。** 在本项目无权四邻接栅格上用 BFS 精确距离及连接，替代论文 A* 距离计算。数值最短距离相同不代表同长路径及附带采集完全相同；采用确定性端点对规范化，属于共同几何实现选择，不宣称作者轨迹复现。
5. **TRACE 虚拟终点解释。** 下一地区中心参与本地 TSP 目标，但最后虚拟连接不在本区执行；实际进入下一地区时另按其局部计划连接。末区自由终点、随后统一返航。不把虚拟中心仅因出现在优化序列就记为实际完成。无前驱时用当前位置，无后继时用自由终点，平局按固定规则。
6. **CAP 已探索区的目标格初始化。** 原文局部 TSP 以 τ_target 为终点，但直接从完整公开快照接入时，没有上一轮探索分支留下的 τ_target。本版在该区相邻未完成格中按原方向顺序初始化；无邻格则按最短距离和坐标平局选择入区格。这是明确的接续适配，不是原文唯一规定；会影响路线，正式横比前必须保留标签并审阅这一选择，不能悄悄替换为我们喜欢的最远点等策略。
7. **CAP 自由终点的文字歧义。** 原文 III-C 先规定无探索节点时终点自由，后续 dummy 构造却将除起点外的 dummy 边设为无穷；照闭环字面执行无法得到有限目标。本实现直接求前述固定起点/自由终点的开放路径目标，**没有声称逐字复现该 dummy 公式或已获作者确认**。
8. **中心及并列规则。** TRACE 中心在残余格内投影；CAP 均值栅格点若可飞可保留（可能是已覆盖格），否则投影回该区。离散取整及并列按确定性坐标规则。不同区域标签即使中心重合也不去重。
9. **内部树记录与中断输出。** 内部节点 R 是分裂时快照，不能当作随时更新的当前任务账本。执行中断可能发生在下一次结构同步之前；诊断路径和逐步 pending 如实保存，但失败的正式 route 为空，不能拿部分结构/路径当完整方案。

上述选择既没有被隐藏，也不因路线合法就自动得到算法忠实性背书。当前可确认的是**这些声明下的公开地图适配实现及有限测试**。

## 5. 审核口径、计时与过程边界

- `audit.py` 不导入算法运行代码，以独立四邻接 BFS/集合账本检查：起点、每一步、可飞域、覆盖、返航、资源、暂缓目标、逐连接采集和最短性、叶/区域任务分区、树索引、父子关系及保留顺序。
- `verify_delivery.py` 在此基础上重查输入及运行源码哈希、原始输出哈希、实际执行的目标序列与 TSP 目标成本、虚拟段成本、预期负例类别、种子间完整语义一致性。再次检查不增加求解次数。
- 输入沿用 C* 已保存的 16+10 个微型用例和 20 个开发道路状态，不挑选新正例。运行前将输入哈希、算法/运行器/审计源码哈希和每项预算写进各批 `protocol.json`，之后未改这些文件。
- 微型每次 5 秒；道路每次 20 秒、独立子进程、35 秒外部看门狗、串行运行。连续两次工作进程异常/看门狗/审核错误则停止，结果不回填。本轮没有发生这些停止条件。
- **实际执行顺序：先单元与微型，随后启动道路；99 项截止专项在道路批次运行期间另行补测。不能把截止专项追认成道路开跑前已通过的门槛。** 这轮属于开发正确性验收，不冒充完整事前正式性能协议。下一轮共同横比必须先全部过门再开跑。
- 截止计时从 solve 内部开始，包含几何、距离矩阵、排序、路线构造、逐步账本与结果构造检查；不含进程导入、输出文件落盘和独立外审。保存字段 `worker_wall` 的计时范围实际上还含父进程读取/审计开销，不应称纯 worker 耗时或用于算法加速比较。
- 检查点是协作式截止，不是每个 Python 操作可抢占的硬实时保证。合成时钟测试只验证已经命中的阶段在 `<、=、>` 边界如何返回；没有证明所有可能调用路径均被穷尽。
- 本版没有截断任务数、添加改良候选、随机扰动、全局补全或借用其他冻结算法作为后备。资源不足直接拒绝，不声称完备的资源约束最优规划。

```powershell
& './运行环境/python/python.exe' -B -X utf8 './TRACE_CAP适配复现_20261020/test_core.py' -v
& './运行环境/python/python.exe' -B -X utf8 './TRACE_CAP适配复现_20261020/verify_delivery.py'
& './运行环境/python/python.exe' -B -X utf8 './TRACE_CAP适配复现_20261020/seal_delivery.py' --verify
```

独立重放单个道路求解，不覆盖本批输出：

```powershell
$d = './TRACE_CAP适配复现_20261020'
$job = Get-ChildItem -LiteralPath "$d/road_evidence/jobs" -Filter '*.json' | Sort-Object Name | Select-Object -First 1
$output = Join-Path $env:TEMP ('TRACE_CAP_replay_' + [guid]::NewGuid().ToString() + '.json')
& './运行环境/python/python.exe' -B -X utf8 "$d/worker.py" $job.FullName $output
& './运行环境/python/python.exe' -B -X utf8 "$d/audit_replay.py" $job.FullName $output
```

单次时钟数值不必相等，固定输入下非计时/种子语义应一致；保存的两种子重复已全量核实。整批重跑要复制到新的验收目录并另建协议，不能删除旧 evidence 再覆盖。跨机器重放需重建 job 的绝对输入路径，保持输入内容哈希。
