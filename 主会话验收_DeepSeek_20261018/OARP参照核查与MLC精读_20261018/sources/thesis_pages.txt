                                               Abstract

We study the problem of planning near-optimal coverage paths for a robot operating in
an environment such that a sensor or tool attached to the robot covers the environment.
We consider environments that contain unknown obstacles that are detected by the robot
during the execution of the coverage path.   Such obstacles necessitate a replan of the
coverage path that safely avoids the new obstacles while still minimizing a cost function
(coverage time, length, and/or turns).
    For an environment with known obstacles, existing coverage planning approaches dis-
courage turns in the path by covering the environment along the least number of coverage
lines, i.e., straight-line paths. This is because turns not only slow down the robot but also
negatively affect the quality of coverage, e.g., tools like cameras and cleaning attachments
commonlyhavepoorperformancearoundturns. However,existingapproachesdonotguar-
antee the minimum number of coverage lines.  To this end, we propose a minimum-turn
coverage planning approach, namely optimal axis-parallel rank partitioning (OARP), that
guarantees coverage along the minimum number of axis-parallel (horizontal/vertical) cov-
erage lines. Using simulations in real-world environments, we show that OARP improves
upon state-of-the-art approaches in terms of turns and coverage time.
    When there are unknown obstacles in the environment, recomputing such paths online
is computationally expensive.  In such cases, the robot may have to wait for a safe path
to continue coverage, resulting in robot stoppages that increase coverage time. To enable
replanning with minimal stoppage, we extend OARP to introduce an anytime coverage
replanning approach.  Upon detecting a new obstacle in the environment, we replan an
initial coverage path obtained from OARP within a given time budget (e.g., time to reach
the new obstacle).   Given this budget, the replanning approach also aims to minimize
the overall path turns and coverage time.   We showcase the replanning framework in
experiments using an industrial cleaning robot avoiding unknown obstacles.
    We then study two problems towards improving upon the above framework. First, we
analyse the length of the coverage paths returned by OARP and obtain an approximation
guarantee that quantifies the sub-optimality of OARP path lengths.  Following this, we
propose an approach that improves upon this approximation factor and computes shorter
coverage paths in practice than OARP. The second problem is to remove the axis-parallel
constraint imposed by OARP on the coverage lines.  We propose decomposing the envi-
ronment into sectors, i.e., possibly overlapping rectangular sub-regions that can each be
covered by straight-line paths parallel to the longest sector edge. Using results from sub-
modular set cover (SSC) problems, we propose a greedy approach to compute sectors and
provide an approximation guarantee on the number of sectors in the decomposition.

2.1   The Coverage Path Planning (CPP) Problem

We start by introducing the CPP problem we focus on in this thesis.   Consider a 2D
(possibly non-convex) environment with known obstacles, where W ⊆R2 is a closed and
bounded set that represents all free points within the environment.  We now consider a
robot with a state composed of its position x ∈ W, where x is a vector in R2, and a
heading θ ∈ [0,2π) radians. The robot is carrying a coverage tool with a footprint given
byA⊆R2. Conventionally, the coverage tool is represented by a simple geometric shape
such as a square of a fixed width l > 0 [37,7,32,88].

Assumption 2.1. The coverage tool is a square with width l > 0.

   LetA(x,θ)⊆W represent the placement of the tool with respect to the robot’s state.
We consider the square coverage tool to be centered at x and oriented along θ. In reality,
the square tool may not be able to cover the entire environment, so we look to cover an
approximation of the environmentfW ⊆ W that the tool can reach.  This includes grid
approximations of W containing square grid cells of width l.  Our goal is to compute a

2.2   Literature Review

The CPP problem has been studied extensively in the robotics literature, with varying
CPP approaches proposed for a wide range of robotic setups.  Many detailed surveys of
CPP approaches can be found in the literature [21,37,12,85].  For the general class of

must be solved using a solution approach that exploits properties of the environment
to plan the coverage path.  Therefore, an important component of the CPP problem is
the environment set W.  Based on prior knowledge of W, CPP methods can be broadly
classified into offline and online approaches.

2.2.1   Offline CPP

In the offline CPP problem, we assume that the environment is known and undergoes no
changes.  Given this, one looks to compute a coverage path that covers the environment.
For the general class of environments, offline CPP is an NP-hard problem [8] and thus
research is primarily on computing approximations to the optimal coverage path using a
variety of solution frameworks. We first briefly discuss the typical solution frameworks for
offline CPP.
    OfflineCPPisawell-studiedroboticsproblem. EarlyworksinofflineCPPinvolveusing
simple heuristics and maneuvers to cover the environment, albeit with minimal guarantees
of completely covering the environment (i.e.,  complete coverage) [15,35,44].   In [70],
a simple algorithm using random cleaning sweeps is proposed for a robot to cover its
environment. The algorithm is as follows: the robot simply moves straight until it reaches
an obstacle, after which it moves back a small amount, turns at a random angle, and
repeats the process. This approach guarantees complete coverage of simple environments
given enough execution time, as the robot is likely to cover new areas with every sweep.
However,whenpresentedwithenvironmentalchallenges,thisrandomwalkapproachwould
require significant execution time to complete the coverage of the environment.
    Toensurecompletecoverageoftheenvironment, modernCPPapproachestypicallyfol-
lowadecomposition-based algorithmicframework,where(i)theenvironmentisdecomposed
into smaller sub-regions, (ii) an optimal coverage path for each sub-region is computed in-

                                                     9

===== PDF page 27; printed page 10 =====
dividually, and (iii) a tour of the sub-region paths is computed to form the coverage path.
Based on the type of decomposition used by the approach, the decomposition-based ap-
proaches can be further categorized into 2 sub-classes: (i) exact decomposition approaches,
and (ii) approximate decomposition approaches.
    Exact Decomposition Approaches:  In exact decomposition approaches, the en-
vironment is decomposed into sub-regions called cells, where the union of the cells gives
back the environment.  In other words, the decomposition does not omit any part of the
environment.  As such, covering each cell guarantees complete coverage of the environ-
ment.  The cells are usually non-overlapping and convex, but this is not always the case.
A popular approach of this class, namely the boustrophedon approach, computes an exact
decomposition of the environment where thecells are not necessarily convex [22]. Each cell
is covered by a path that either sweeps the cell (i) back-and-forth along coverage parallel
lines [22] (illustrated in Fig.2.1(b)), (ii) along spiral paths [17], or (iii) a combination
of both [16].  There are also turn-minimizing approaches that cover each cell in a locally
optimal direction, generally determined using the cell’s geometry [46,9,28].  Huang [46]
studies an approach that computes a minimum-turn coverage path for each cell in a con-
vex decomposition by using the cell’s minimum altitude, i.e., orienting the cell where its
”height” is shortest.
    As exact decompositions do not omit any region in the environment, they typically
guarantee complete coverage of the environment.  However, there are a few drawbacks
that stem from this guarantee.  For environments with complex boundaries, specifically
cluttered environments, the decomposition is likely to contain many narrow cells that are
notaswideasthecoveragetool. Werefertothisasan over-decomposition, whichtypically
results in instances of redundant coverage.  For cluttered environments, computing these
cells may require time and cause unnecessarily overlapping coverage paths.
    ApproximateDecompositionApproaches: Approximatedecompositionsareenvi-
ronment representations where the union of the cells does not give the exact environment.
A grid decomposition of an environment is an example, as illustrated in Fig.2.1(c). Grid-
based CPP approaches use an approximate representation of the environment as a set of
(usually square) grid cells and compute a path that covers all of them.  This path can
be computed either by solving the traveling salesman problem (TSP) [12], using a wave-
front algorithm to determine visitation order [93], or using a spanning tree of the grid
cells (Spanning Tree Coverage or STC) [32].  STC is a widely studied approach for CPP
in grid approximations, where a spanning tree generated in the grid is used to plan the
coveragepath. ManyvariationsofSTChavebeenproposedinlaterstudies[33,34,87,57].
Turn-minimizing grid-based CPP approaches additionally look to minimize the number of
axis-parallel (horizontal or vertical) coverage lines in the coverage path [88,57].

===== PDF page 28; printed page 11 =====
    Grid-based approaches have also been introduced with approximation guarantees on
the resulting coverage path length [8] and turns [7,30].  In fact, given a square coverage
tool of widthl, the STC approach is shown to provide coverage paths with optimal lengths
for coarse grids with cells of width 2l each [32].  However, a similar guarantee is difficult
to achieve for general grid environments.  Arkin et.  al.  proposed a 6/5 approximation
algorithm for minimum-length coverage planning, but it does not aim to minimize the
number of turns in the path [8].  Approximation algorithms for minimum-turn coverage
planningtypicallyresultinlongerpaths[7,30]. Laterinthisthesis, weproposeanapprox-
imation algorithm to plan minimum-length coverage paths, while also aiming to minimize
the number of turns in the path that achieve comparable performance to turn-minimizing
approximate approaches [88,9].

2.2.2   Online CPP

Wenowshiftourfocustoonlinecoverageplanning,wheretheCPPapproacheitherassumes
partialornoknowledgeoftheenvironmentandplansthecoveragepath during thecoverage
operation.  To detect unknown obstacles in the environment, the coverage robots carry a
sensor to observe the environment online. In sensor coverage applications, the same sensor
may be used for obstacle detection and coverage. Complete coverage of such environments
is difficult to guarantee, but online CPP approaches aim to maximize area coverage given
the current observed state of the environment.
    Online CPP approaches have gained recent interest, and as such, there is a wide range
of different approaches in the literature. Similar to offline CPP, decomposition-based ap-
proachesaretypicallyusedforonlineCPP,whicharefurtherclassifiedinto(i)exactdecom-
positionand(ii)approximatedecompositionapproaches. Apartfromdecomposition-based
approaches, we also review decomposition-free online approaches that have gained recent
popularity.
    Exact Decomposition Approaches: Early approaches in online CPP aim to com-
pute exact decompositions of the environment during coverage.  Acar et.  al.  [2] propose
an approach that incrementally decomposes the environment into cells by detecting con-
nectivity changes in the environment (e.g., areas split by obstacles). Each cell in the de-
composition can be covered using a boustrophedon (back-and-forth sweep) path. However,
this approach assumes access to a short-range occupancy sensor to detect connectivity
changes while executing a boustrophedon coverage path [1].  For long-range occupancy
sensors, a modification of this method was proposed by [3].  Here, the coverage planner
constructsageneralizedVoronoidiagram(GVD)oftheenvironmentduringcoverageplan-
ning.  The GVD is used to generate a hierarchical decomposition of an environment into

                                                    11

===== PDF page 29; printed page 12 =====
(i) vast regions, which are covered using boustrophedon paths, and (ii) narrow regions,
which are covered by following the GVD edges.  Online exact decomposition approaches
guarantee complete coverage for unknown static environments, but also suffer from over-
decomposition, similar to analogous offline approaches, resulting in long coverage paths
with many turns.
    Approximate Decomposition Approaches:  Grid-based methods extend well for
online CPP as one can easily update a grid with new occupancy information. A popular
approach of this class is online spanning tree coverage, i.e., Online-STC [34,33].  This
approach is similar to the offline STC approach introduced in the previous section [32],
except that the spanning tree of the grid cells is incrementally constructed online.  With
new obstacle-free grid cells detected, the spanning tree and, by extension, the coverage
path are changed to cover the new region. However, given a square coverage tool of width
l, online-STC methods are generally applied to coarse grids with cells of width 2l and do
not generalize well to finer grids with cell width l.
    Other grid-based online approaches use various local search and optimization methods
to determine the coverage plan in an unknown environment. Song et. al. [81] propose an
approach using artificial potential fields (APF) to determine a coverage path online. The
APF is used to assign a value to each grid cell that indicates whether the cell is covered,
uncovered, or occupied.  Depending on the value, the robot decides which neighboring
grid cell to cover next. A similar technique to APFs is using bio-inspired neural networks
(BINNs) to model and search the environment.  This was originally proposed by Luo et.
al. [58] and has gained popularity in many recent works [65,84,38]. However, these local
search-based approaches are susceptible to dead-locks, where the robot enters a failure
state where it either does not know where to navigate to, or is in a fatal state where the
robot cannot continue coverage autonomously.  Dead-locks are expensive to resolve and
affect overall coverage time.
    To plan minimum-turn coverage paths online, the above approaches can be modified
to penalize turns in a local search cost function.  However, other grid-based approaches
can be used to guarantee minimum turns in the path overall [75,51].  These approaches
usually involve solving an optimization problem defined on the grid graph. In [50,51], a
hexagonal grid is used to plan turn-minimizing coverage paths online for non-holonomic
robots.
    Decomposition-free Approaches: Online coverage planning shares similarities with
exploration planning, which involves covering unknown environments using sensors [26].
Exploration planning algorithms use information theory [24,45] and frontiers [92] to de-
termine the next-best scan of the environment, rather than using decompositions.

                                                     12

===== PDF page 30; printed page 13 =====
    A popular approach of this class, namely Boustrophedon A∗ (BA∗) was proposed by
[90]. Here, the robot starts by executing a single boustrophedon coverage path to cover a
part of the environment, without constructing an exact decomposition.  While executing
this path, the robot’s sensor is used to detect points in the environment that the current
boustrophedon path cannot reach. For example, an obstacle in the environment may force
the robot to turn before reaching this point. These points are referred to as backtracking
points, as they are starting points for a second boustrophedon path that can be executed
after the first.   From the set of all backtracking points detected during coverage, the
A∗ algorithm is used to pick the best starting point for the next boustrophedon path.
Further variations of this approach have been proposed in later works [89,20]. Recently,
a decomposition-free online coverage planner was proposed that uses frontiers and search-
based planning to identify the next-best region to cover [56].

2.2.3   Multi-robot CPP

Each of the above-discussed approaches is predominantly used for single-robot CPP. For

2.3   Preliminaries

2.3.1   Graphs

A graph G = (V,E) is defined as a tuple of two sets:  a set V  of vertices, and a set
E = {(u,v) | u,v ∈ V} of edges connecting pairs of vertices.  A directed graph G is one
where each edge (u,v) in the graph has a direction.  More specifically, the edge (u,v) is
an ordered tuple indicating flow from vertex u to v. In contrast, an undirected graph has
edges (u,v) which are unordered tuples that each indicate flow between vertices u and v
in any direction (u to v, or v to u).
    InChapters3and4, weproposeCPPapproachesthatusedirectedgraphsderivedfrom
a square grid representation of an environment. Specifically, we use the node-arc incidence
matrix derived from these graphs.

Definition 2.1 (Node-Arc Incidence (NAI) Matrix). The node-arc incidence matrix B of
a directed graph G is a |V|×|E| matrix, where vi is the vertex corresponding to row i, ej
is the edge corresponding to column j, and
                                      −1    if ej leaves vertex vi

                              Bij =    1       if ej enters vertex vi    .
                                         0       otherwise

    An important property of NAI matrices is total unimodularity.

Definition 2.2 (Total Unimodularity (TU) Matrix). A matrix B is said to be a totally
unimodular (TU) matrix if every square sub-matrix of B has determinant d∈{0,1,−1}.

    We use the TU property of NAI matrices in chapters3and4to show that we can
compute partitions of the environment efficiently.

2.3.2   Matching Problems in Graphs

Given an undirected graph G = (V,E), a matching M ⊆ E is a set of edges in the graph
where no two edges in M share a common vertex.  A vertex v is said to be matched if
there exists an edge e∈ M that is incident upon v. We use concepts of vertex matching
in Chapters4and5.

===== PDF page 32; printed page 15 =====
Definition2.3 (PerfectMatching). A matching M ⊆E of a graph G = (V,E) is a perfect
matching where all vertices v∈V  are matched.

    A graph G = (V,E) can only contain a perfect matching if it has an even number of
vertices.  The size of the resulting matching |M| = |V|/2.  For other types of graphs, a
maximal matching |M|≤|V|/2 can be computed that maximizes |M|, but in this thesis,
we will only deal with graphs that allow perfect matchings.

2.3.3   Traveling Salesman Problems

The coverage path planning problem is analogous to traveling salesman problems (TSP).
We exploit this relationship in the algorithms proposed in this thesis.
    Givenanundirectedcomplete(fully-connected)graphG = (V,E), acycleisasequence
of vertices C = (v1,v2...,vk,v1), where only v1 is visited twice. A tour T is a cycle that
visits all vertices v ∈ V  in the graph (except the start vertex). For each edge (u,v)∈ E,
where u,v∈V, let J(u,v) be a cost associated with the edge. Given a tour T, let the cost
of the tour J(T) =Pk−1i=1 J(vi,vi+1)+J(vk,v1).

Definition2.4 (TravelingSalesmanProblem(TSP)). Given an undirected complete graph
G = (V,E) and a cost function J as above, the traveling salesman problem is to compute
a tour T that minimizes the cost J(T).

    The generalized traveling salesman problem (GTSP) is a variant of TSP where the
vertices V  are partitioned into m sets {V1,V2,...Vm}, i.e., Vi∩Vj = ∅ and ∪mi=1Vi = V.
ThegoalofGTSPistocomputeacycleC inGthatvisitsexactlyonevertexineachofthe
m sets and minimizes the cost J(C). The GTSP problem shows up in almost all chapters
of this thesis, with details provided in Chapters3and4.
Metric-TSP: Both TSP and GTSP are NP-Hard problems, but effective heuristics have
been proposed to efficiently compute good solutions in practice [40,68].   However, we
review a special class of graphs for which there exists an efficient algorithm to solve TSP
with approximation guarantees. We use similar concepts to this algorithm in Chapter5to
designanapproximationalgorithmforminimum-lengthCPPwithturncostconsiderations.
    Consider a graph G = (V,E), where each edge (u,v)∈E has a cost J(u,v). Addition-
ally, we consider that the cost function has the following properties:

  (i) Non-negativity: J(u,v)≥ 0 for all u,v∈V,

                                                   15

===== PDF page 33; printed page 16 =====
 (ii) Symmetry: J(u,v) =J(v,u) for all u,v∈V

 (iii) Triangle inequality: J(u,v)+J(v,w)≥J(u,w) for all u,v,w∈V.

    A function J(u,v) that satisfies the above properties is called a metric function, and
we refer to G as a metric graph.  The traveling salesman problem defined on G is called
the metric traveling salesman problem or metric-TSP.
    Given a complete metric graph G = (V,E) as determined by the edge cost function J,
Christofides [23] proposed a 1    .5-approximation algorithm, which is briefly described here.
Thealgorithmstartsbycomputingaminimumspanningtree(MST)inG. GiventheMST,
let O be the set of vertices in the MST that have an odd degree. Since G always contains
a tour (complete graph), O must have an even number of vertices.  One can therefore
compute a minimum-weight perfect matching M  of the vertices in the sub-graph of G
induced by the vertices in O. Combining the edges of the MST and M, we get a sub-graph
G′ of G that contains only even-degree vertices. Such a graph contains an Eulerian circuit.
Definition 2.5 (Eulerian circuit). An Eulerian circuit in a graph G is a walk along a
sequence of edges that visits each edge exactly once.

    The Eulerian circuit may revisit vertices in the graph, in which case a shortcut using
other edges in G is found to compute a tour T. The length of the Eulerian circuit is 1.5
times the TSP tour cost in the worst case, thus giving rise to the approximation factor.

existing approaches to compute the tour [80,68].  We employ a similar formulation that
was proposed in [11] and create an auxiliary graph representing all possible connections
betweentheranks. Theverticesofthisgrapharegroupedintosets, whereeachsetconsists
of two vertices representing the two directions to cover the rank (e.g., for a horizontal line
we can cover it from left to right or right to left). The GTSP aims to minimize the cost of
visiting one vertex in every set (traversing each rank in a specific direction).
    The edge costs between the vertices in different sets of the auxiliary graph are given
by the time to travel between rank endpoints along an obstacle-free transition path. These
transitionpathsareplannedusingthedynamicsoftherobot,whichdependsontherobot’s
design.  For this work, we assume semi-holonomic dynamics where (i) the robot stops to
turn in-place with a constant angular velocity, and (ii) the robot has piecewise constant
acceleration (when accelerating or decelerating) while travelling in a straight line with
a maximum linear velocity.   The same dynamics model is used in [88] and [9], which
we compare our method against in Section3.6.   We compute each transition path by
constructing a visibility graph within the IOP boundaries and planning the shortest path
usinganA*searchwiththestraight-lineEuclideandistanceusedastheheuristic[69]. The
resulting path is a sequence of straight lines and intermediary turns, for which the travel
time is computed.

3.7   Summary

In this chapter, we proposed the OARP coverage planning method that aims to minimize
the number of turns needed to cover the robot’s environment. We do this by partitioning
the environment into thin axis-parallel ranks using a linear program (LP). We proved
that this formulation computes the optimal rank partitioning in polynomial time.  We
then conducted experiments on maps of real-world environments and showed that OARP
always achieves the best rank partition in comparison with the state-of-the-art method.
Furthermore, OARP is also shown to have around 6% lesser turns and 3% shorter coverage
tours on average than the other method.

   One approach to coverage replanning is to stop executing the current coverage path

example of local replanning would be where the robot simply drives around the obstacle
whenever a collision is imminent. However, a more practical approach would be to use the
time while driving towards the blockage to find more optimal solutions.  In this chapter,
we propose an anytime coverage replanner that utilizes the time spent driving to conduct
near-optimal replans on the provided coverage paths (see Fig.4.1).

4.5   The TOUR-REPLAN Subroutine

In this section, we describe our approach to compute a tour of the replanned ranks to
obtain our new coverage path. Similar to the approaches from [11] and [74], we formulate
this as a Generalized Travelling Salesman Problem (GTSP) on a fully-connected auxiliary
graph representing all connections between ranks. Each set in the graph represents a rank
and consists of two vertices to represent the directions in which the rank can be traversed.
We call these sets as rank sets. The edge costs are the transition times between two ranks,

                                                      54

===== PDF page 72; printed page 55 =====
i.e. thetimefortherobottotravelfromonerankendpointtoanother. Sincethetransition
times depend on the robot’s design and dynamics, we compute the edge costs by assuming
dynamicssimilarto[74]and[88],where(i)therobottraversesastraightlinewithpiecewise
constant acceleration with a maximum velocity and (ii) the robot stops and turns in place
with a constant angular velocity. Solving GTSP on this graph obtains a tour that covers
each rank while minimizing the transition times between the ranks.  In Section4.6.1, we
provide more details on the robot dynamics parameters used to compute transition times
in our simulations.
    However, we look to address two additional challenges in the tour replan.  Firstly, we
look to limit the size of the GTSP instance by considering only the interrupted sections
of the initial path.  Fig4.9gives an illustration of possible path interruptions caused by
(i) ranks changing orientations (ii) ranks split by an obstacle, and (iii) unreachable ranks.
The ranks that are unchanged correspond with sub-sections of the initial path that are
unchanged. We retain each such section by representing it as its own GTSP set, consisting
of two vertices representing possible traversal directions.  We refer to this set as a path
set. The GTSP is computed on a graph containing these path sets and rank sets that each
represent a new rank obtained from RANK-REPLAN to be added to the tour.
    The second challenge is that we must also take into account the position of the robot
and the desired end of the tour.  To address this, we add artificial start and end vertices
to the GTSP graph, as in Fig.4.9.  To ensure that the solution is a path from the start
vertex to the end vertex, we add a directed zero-cost edge from the end vertex to the start
vertex. Solving the GTSP on this graph gives us the replanned coverage path.
    In this chapter, we created a fully-connected auxiliary graph.  There are alternative
approaches where the auxiliary graph need not be fully-connected, such as those using
lazy edge evaluations to compute a tour [77].  However, the above challenges must still
be addressed for such a formulation using the approach described for the fully-connected
case.

4.8   Summary

We proposed an anytime coverage replanning approach called OARP-Replan to replan
coverage paths for environments with unknown static obstacles. OARP-Replan solves this
problem in two stages:  (i) rank replanning, and (ii) touring.  The first stage replans the
ranks (straight-line paths) of an obstructed coverage path, while the second stage com-
putes a tour of the replanned ranks to obtain the new path.  We proposed two integer
linear programs (ILPs) that each solve the rank replanning stage so that the resulting
touring stage is completed within a time budget τ. Simulations on maps of real-world en-
vironmentsshowedthattheOARP-ReplanvariantsusingeachILPachievebettercoverage
performancethanagreedyreplannerandstate-of-the-artcoverageplannersusedforonline
replanning [74,88,56]. Moreover, we also compared OARP-Replan with offline planning
approaches (treating all obstacles as known) [9,5] where we observed an improvement
in total coverage time.  Finally, we demonstrated the proposed approach by replanning
coverage paths for an industrial-level cleaning robot.
    In this work, we focus only on the case of new obstacles in the environment. The case
where an obstacle is observed and later removed from the environment (including dynamic
obstacles) is left for future work.  This would involve detecting areas in the environment
that could be free at a later time due to an obstacle removal and returning to cover
them without long detours. Another future direction involves replanning using predictions
about environment occupancy to balance coverage and exploration, which are competing
objectives.  To balance them, the coverage planner must determine when to replan the
coverage path, perhaps even delaying a replan until more information about an obstacle is
collected.
    In the rest of the thesis, we will address two issues with the OARP-based frameworks:
(i)obtainingguaranteesonthecomputedcoveragepath,and(ii)removingtheaxis-parallel
constraint on the coverage lines.

Chapter 5

CPP with Approximation Guarantees




We now shift our focus to improving the coverage replanning by analysing the length of
OARP coverage paths and establishing an approximation factor for the OARP approach.
We then propose an improved approximation algorithm to connect axis-parallel coverage
lines into a minimum-length tour.  The proposed approach can also be used lazily, i.e.,
without evaluating all possible transition paths. This offers a speed-up that can be useful
to replan more of the coverage path upon detecting unknown obstacles.

5.1   Introduction

For general environments, CPP is an NP-hard problem [8], thus optimal planning ap-
proaches do not scale well with increasing problem complexity.  So, as we discussed in
Chapter3, CPP algorithms [22,5,88,74] usually follow the following framework, where
they: (i) decompose the environment into sub-regions, (ii) compute an optimal set of par-
allel straight-line paths or coverage lines to cover each sub-region, and then (iii) compute
a cost-minimizing tour of the coverage lines to form a coverage path. In this chapter, we
refer to this approach as the line-touring framework. This framework is commonly used to
minimize the number of turns in the coverage path as (i) turns take time to execute while
adding little to no new coverage, and (ii) tools like cleaning attachments miss coverage
during turns [5,88,74,7].
   Whilethisframeworkmakestheproblemmoretractable, it, ingeneral, computespaths
with suboptimal length.  This is acceptable as long as the computed solution is “good
enough” with a known approximation factor.  While approximation algorithms for CPP

                                                  70

===== PDF page 88; printed page 71 =====
have been studied [8,29], an approximation factor for the line-touring framework has not
beenanalyzed. Inthiswork, westudytheline-touringframeworkappliedtogriddecompo-
sitions,wheretheenvironmentisrepresentedasasetofsquaregridcells. Eachcoverageline
covers a rank, i.e., a group of grid cells aligned along an axis-parallel (horizontal/vertical)
straight line. As such, one can obtain the coverage lines for a grid decomposition by par-
titioning it into these ranks.  We refer to this variation of the line-touring framework as
rank-touring [88,74,31].
    In this chapter, we show that the rank-touring framework achieves an approximation
factor of (1+1.5γ) for path length, where γ > 1 is the approximation factor to solve the
metric traveling salesman problem (metric-TSP). Following this, we propose a (1.5+ϵ)-
approximation algorithm, namely Minimum Length Coverage Approx (MLC-Approx), for
minimum-length CPP in connected grid environments with holes. Here, ϵ≪ 1 is a small
term proportional to the number of ranks.  Building upon the rank-touring framework,
MLC-Approx relaxes the turn minimization objective to compute paths with near-optimal
length, while still achieving fewer turns than a TSP planner.

5.2   Problem Definition

5.2.1   Rank-touring Framework

We start by clarifying the notation for the rank-touring framework we will use in this
chapter.  As discussed in previous chapters, the rank-touring framework starts by par-
titioning the IOPfW  into non-overlapping axis-parallel (i.e., horizontal/vertical)  ranks
R ={r1,r2,...,rm}, where each rank ri ∈ R is a set of grid cells that can be covered in
a straight-line sweep using a square tool of width l.  Let PR be the set of coverage lines
that each correspond to a rank in R. For example, the coverage line of a horizontal rank
ri is a path connecting the centers of its leftmost and rightmost grid cells. The framework
then computes a cost-minimizing tour of the paths in PR to obtain a coverage path for the
IOP. The resulting coverage path P is a sequence of coverage lines in PR and collision-free
transition paths connecting two coverage lines at their endpoints. The aim of the tour is
to minimize the cost J(P) associated with the transition paths.

5.4   A (1.5+ϵ)-Approximation Algorithm

We now present a (1.5+ϵ)-approximation algorithm for Problem5.1, called the Minimum
Length Coverage Approx (MLC-Approx) algorithm.  MLC-Approx modifies the touring
step in the rank-touring framework to improve the guarantee on the path length. Instead
of connecting ranks at their endpoints, MLC-Approx allows the breaking and merging of
neighboring ranks while minimizing the path length added to the final coverage path. We
consider that the IOP is connected, i.e., there exists a path between every pair of grid cells
with axis-parallel motions.

resulting set of coverage lines for an example IOP.

We propose two strategies to merge adjacent sub-tours, namely double edge merging and
corner junction merging. In both strategies, we exploit the layout of the adjacent (neigh-
boring) grid cells covered by two sub-tours to determine a merging strategy that limits
the path length added. For the rest of this section, let the two sub-tours to be merged be
represented by S and  ¯S.  With some abuse of notation, we say that a grid cell ci ∈ S if
sub-tour S covers the cell ci.
    Double Edge Merging: Asimplestrategytomergesub-toursistoadda double edge
between the two adjacent grid cells ci∈S and ¯ci∈ ¯S. Specifically, we add a traversal path
from ci to ¯ci and another path from ¯ci to ci.  During coverage, the coverage tool follows
this double edge, where it moves from sub-tour S to sub-tour ¯S, covers ¯S, and returns to
finish coveringS. Given that the coverage tool width is l, the length added to the coverage
path using this strategy is 2l. Additionally, since we consider the IOP to be connected, all
sub-tours arising from the perfect matching can be merged using double edges to form a
single tour.

during the merge. Consider the case where two adjacent grid cells ci,cj ∈S share a corner

the path length added. First, consider the case where sub-tour S has an edge (ci,cj) and
sub-tour ¯S has an adjacent and parallel edge (¯ci, ¯cj) connecting the corresponding pairs of
cells (Fig.5.3(a)). In this case, we simply perform an         edge swap, where we replace these

5.4.4   Turn Minimization

While the use of a minimum rank partition minimizes the number of ranks in the coverage
path, we must also minimize the turns added during the sub-tour merges. To do this, we
usea weighted sub-touradjacencygraphtocomputetheorderinginLine3ofMLC-Approx
(Algorithm2), where the edge weights are given by the minimum number of turns added
by merging two adjacent sub-tours.  We then compute a minimum spanning tree (MST)
in this graph to determine the sub-tour pairs to be merged. When merging two adjacent
sub-tours (as per MST edge), we pick the merge strategy that minimizes the number of
added turns.  Typically, this leads to merges occurring at the ends of ranks, as they add
fewer additional turns to the final coverage path.

5.7   Summary

This chapter studied minimum-length coverage path planning (CPP) for robots using grid
decompositions of environments. The rank-touring framework introduced by recent CPP
approaches [7,88,74] guarantees a coverage path of length (1+1           .5γ) times the optimal,
where γ ≥ 1 is the approximation factor for metric-TSP. To improve this bound, we pro-
posed the MLC-Approx algorithm, which modifies the rank-touring framework to achieve
an approximation factor of (1.5+ϵ), where ϵ≪ 1 is proportional to the number of ranks
(straight-line paths).  Empirically, MLC-Approx plans coverage paths with near-optimal
lengths in comparison with state-of-the-art CPP approaches [74,88,9].   MLC-Approx
paths also have comparable “straightness” to turn-minimizing CPP planners, which is de-
sirable for path tracking. A lazy variation of MLC-Approx was also proposed for efficient
computation of these paths.
    ThecoretechniquesofMLC-Approx(matchingandsub-tourmerging)areapplicableto
anyrank-touringapproachthatminimizesranks. Forreal-worlddeployment,MLC-Approx

6.1   Introduction

While at the cost of solution quality, coverage planning approaches in literature use the
following framework to make CPP more tractable: (i) decomposing the environment into
sub-regions that can each be individually covered, and (ii) computing a visitation order or
a tour of the sub-regions. The environment decomposition step is critical as it determines
the majority of the coverage path, and also affects the cost of the tour connecting the
sub-regions. Therefore, it is important to compute good decompositions that account for
these effects on the path.
   Recallthat,intheliterature,CPPalgorithmsaregroupedintoexactorapproximateap-
proaches depending on the choice of decomposition. Exact approaches usually decompose
the environment into convex or monotone sub-regions called cells or “sectors” [9,46,5].
In this chapter, we refer to these sub-regions as sectors.  Each sector is then covered by
a lawnmower path (i.e. using parallel coverage lines) along an optimal orientation as de-
termined by the geometry of the sector. However, when applied to complex environments

                                                 88

===== PDF page 106; printed page 89 =====
with irregular boundaries, exact CPP approaches are susceptible to over-decomposition
where some sectors are thinner than the coverage tool. This is a consequence of covering
the entire environment and results in many instances of double coverage where the robot
returns to areas it has already covered.
    Inpreviouschapters, wehadproposedCPPapproachesthatminimizesdoublecoverage
by minimizing the number of coverage lines (i.e. straight-line paths). This falls under the
broadcategoryofapproximateCPPapproachesthatusegriddecompositionstocoverareas
thatarereachablebythecoveragetool. Thedecompositioniscomposedofnon-overlapping
(usually square) grid cells of size equal to the coverage tool [57,47,74,75]. However, using
grid cells constrains the robot to cover the environment along axis-parallel (horizontal or
vertical) orientations, leading to sub-optimal “staircase-like” coverage paths.  We seek a
decomposition that addresses the shortcomings of both exact and approximate approaches
by (i) preventing over-decomposition and (ii) removing axis-parallel constraints.
    In this chapter, we propose a decomposition of the environment into possibly overlap-
pingrectangularsectors. Wechooserectanglesforthefollowingreasons: (i)thelawnmower
path to cover a rectangle can be optimally oriented along the longest edge [46], and (ii)
one can efficiently identify the largest rectangle in an environment [60,27].  We refer to
this as the sector decomposition problem.  Inspired by works in sensor coverage [25,61],
we leverage the submodularity property of covering the environment with sectors to design
our solution approach. Specifically, we show that the sector decomposition problem is an
instance of the submodular set cover (SSC) problem, which has been studied extensively
in the literature [91,48,19]. In our proposed approach, we use the result that the greedy
algorithm for SSC has a well-known approximation guarantee [91].
Chapter contributions: Our specific contributions are as follows:

   1.We formulate the sector decomposition problem that aims to minimize the number

   2.We propose a greedy algorithm to solve the sector decomposition problem, with an

6.4   Sector Decomposition Approach

We now describe our solution approach for sector decomposition. We look to greedily add
large rectangular sectors to the decomposition that cover new areas of the environment.
We first describe the greedy step that leverages computational geometry algorithms to
identify the largest candidate sector in the environment (or its subset). We then present
the greedy algorithm that computes a sector decomposition while constraining the overlap
between the sectors.  For the case where the overlap is not constrained, we provide an
approximation factor for the greedy algorithm following [91].

6.4.1   Sector Identification

We first look to identify the largest candidate sector (i.e. the rectangle of maximum area)
for a given environment W (or its subset).  One can efficiently compute the largest area
axis-parallel rectangle in the environment [60,27].  Also, for coverage planning, one may
constrain the robot’s coverage directions using the orientations of the environment’s edges
(boundary and holes), so that the robot covers along long walls and moves predictably
[46,9,5].
    To identify the largest sector, we use a polygonal representation ofW and extract a set
of candidate orientations Θ using the polygon’s edges. We limit our candidate sectorsQ to
rectangles oriented along every θ∈ Θ. We then obtain the largest axis-parallel rectangular
sector inW for each θ using existing approaches [60]. Repeating this process for every     θ,
we form the set  ¯Q of candidate sectors for the greedy step.

6.4.2   Greedy Decomposition

We propose an algorithm that decomposes the environment W by greedily choosing rect-
angular sectors that cover the largest remaining uncovered area. The pseudocode is given
in Algorithm3. Until the minimum coverage of the environment is achieved (Line3), we
compute candidate sectors  ¯Q for each orientation θ∈ Θ (Line4). We then pick the can-
didate sector Q ∈  ¯Q covering the largest additional area, add it to our decomposition S
(Lines5-6). We then remove the area it covers from the environment to avoid overlapping
coverage with future candidate sectors (Line8).

β.  Only  ¯Q is removed from the environment so that future sectors may overlap with Q.
Setting β to 0 leads to disjoint sectors, while arbitrarily large values lead to unconstrained
overlapping.

6.7   Summary

We proposed an environment decomposition approach for robot coverage planning called
sector decomposition. The approach decomposes the environment into the minimum num-
ber of rectangular sectors, where each sector is covered using a lawnmower path oriented
along its longest edge.  We showed that sector decomposition is an instance of the sub-
modular set cover (SSC) problem, and proposed a greedy algorithm with a guarantee on
the number of sectors in the decomposition. Finally, we present coverage planning results
using the proposed approach for real-world environments and show that it improves upon
existing coverage planning approaches [9,74].
    Whileweuselawnmowerpathstocovereachsector, onemayuseOARPinconjunction
with the sectors to compute the minimum number of ranks oriented at multiple angles.
A future direction of this work is such a combination to minimize the number of turns in
the coverage path generated using sector decomposition, for cases when robot turning is
detrimental to coverage time and quality.

Chapter 7

Conclusions and Future Work




Coverage path planning (CPP) is the task of planning a robot’s path such that the
tool/sensor being carried by the robot covers all points in its environment. Additionally,
CPP aims to minimize the cost associated with the path, such as length, turns, and/or
coverage time. While CPP is NP-Hard for known environments [8], the complexity of the
problem increases further when unknown obstacles are introduced into the environment.
In this thesis, we studied the problem of coverage path planning for partially unknown
static environments.
   InChapter3,weproposedtheoptimalaxis-parallelrankpartitioning(OARP)approach
to compute minimum-turn coverage paths for known non-convex environments with ob-
stacles.  The key to OARP is that we can partition the environment efficiently into the
minimum number of axis-parallel (horizontal/vertical) thin rectangles called ranks that
can each be covered along a straight-line path. We then compute a generalized traveling
salesman problem (GTSP) tour of the ranks to compute a coverage path such that the
transition time between the rank endpoints is minimized. We presented simulation results
with two datasets of maps and compared against state-of-the-art CPP approaches in the
literature [88,9].  We also showcased an industrial cleaning robot executing a path gen-
erated using OARP for an example environment in a high-fidelity robot operating system
(ROS) simulation.
   In Chapter4, we extended OARP to replan coverage paths upon detecting new static
obstacles in the environment. We aim to conduct path replans that minimize the robot’s
drive time and stoppage time resulting from the robot not having a safe path to continue
coverage, i.e., from computationally expensive replans.  We proposed OARP-Replan, an
anytime coverage replanning approach, that uses the time available before reaching the

                                                 104

===== PDF page 122; printed page 105 =====
first newly detected obstruction to replan as much of the interrupted coverage plan op-
timally (few turns as possible).  To incorporate the time budget, we modified OARP to
consider the coupling between the rank partitioning and the touring steps.  We showed
that OARP-Replan computed optimal replans of the coverage path if given a large enough
time budget, i.e., enough time to reach the new obstacle.  We showcased this approach
using extensive simulations and real-world experiments with an industrial cleaning robot,
where we observed an improved performance against several baseline approaches, specifi-
cally resulting from achieving fewer turns in the coverage path with little to no stoppage
resulting from the replanning. Moreover, in our robot experiments, OARP-Replan enabled
a large cleaning robot to reach and cover narrow areas in the environment caused by new
obstacles.
    We then focused on two improvements to the planning approaches proposed in the
previous chapters.  In Chapter5, we proposed a modification to OARP that computes
minimum-length coverage paths with approximation guarantees, while minimizing turns
as a secondary objective.  We started by showing that the rank-touring framework (e.g.,
OARP) to compute coverage paths achieves an approximation factor of (1+1.5γ) on the
coverage path length, where γ is the approximation factor to solve the metric-TSP. We
then proposed an improved (1.5 +ϵ)-approximation algorithm called MLC-Approx that
can replace the GTSP step in OARP. Here, ϵ<< 1 is proportional to the number of ranks
in the environment’s coverage path.  In practice, we show that MLC-Approx computes
paths with near-optimal lengths and comparable “straightness” to minimum-turn CPP
approaches like OARP. Moreover, we also proposed a lazy variation of MLC-Approx that
computes paths quicker without losing the approximation guarantees.  This lazy variant
offersalargespeedupinpathcomputationandcanenablefasterreplansofcoveragepaths.
    Finally, in Chapter6, we remove the axis-parallel constraint introduced in OARP by
computing an approximate decomposition that allows coverage along multiple directions.
We propose decomposing the environment into the minimum number of sectors, which
are possibly overlapping rectangular sub-regions.  Each sector can be covered in parallel
straight-line paths oriented along its longest edge.  We showed that the sector decompo-
sition problem is an instance of the submodular set cover (SSC) problem, for which the
greedy algorithm achieves the best-known approximation guarantee.  Following this, we
proposed a greedy algorithm for sector decomposition that incorporates techniques from
computational geometry to identify sectors in the environment [27,60].  Given a mini-
mum desired coverage ratio of γ (i.e., fraction of environment area covered), we obtained
an approximation guarantee of 1 + ln(  11−γ) for the greedy approach.  In simulations, we
obtained intuitive decompositions of non-orthogonal complex environments resulting in
shorter coverage times than axis-parallel paths.

7.1   Future Work

While this thesis studies algorithms to compute near-optimal coverage paths for partially
unknown environments, there are still some challenges that are yet to be solved. Specifi-
cally, we identify the following two topics for future work in this domain.

Obstacle Predictions: The coverage replanning approach proposed in Chapter4regis-
ters a new obstacle using sensor readings collected before a replan.  However, for a large
obstacle that is not visible at once, the replanning is done in parts, where each replan uses
parts of the obstacle that have been observed by the sensor at different replans. This may
result in a replanned path with some sub-optimal detour paths that may be prevented if
moreinformationabouttheobstaclewasavailableatthefirstreplan. Tomitigatethis, one
may predict the shape and size of a partially-observed obstacle, which can then be used
to compute replanned paths closer to the optimal.  This approach can be especially use-
ful if there are recurring obstacles across multiple coverage planning missions. A possible
direction towards this predictive coverage replanning approach is to use modern mecha-
nisms like deep neural networks [42] to generate predictions about the obstacles or whole
environments that can be incorporated in a replanning approach like OARP-Replan.

Early Environment Exploration:  Consider a cleaning robot exploring an unknown
warehouse environment using a long range LIDAR scanner while covering with a smaller
vacuum attachment. In this case, the sensor has a much larger footprint than the vacuum
tool, so a coverage path for the vacuum tool will guarantee exploration of the environment
with the sensor. However, when covering cluttered environments with unknown obstacles,
one may want to detect new obstacles earlier in the coverage path so more time is available
to replan the coverage path such that the overall coverage time is minimized.   In the
cleaning robot example, early exploration of a large obstacle in a occluded section of the
warehouse may allow enough time for the robot to replan a cost-minimizing coverage path
that avoids it. For CPP applications where robustness is an issue (i.e., dead-locks due to
no safe paths), early exploration of uncovered environments may help identify areas where
the robot is likely to get stuck. Therefore, future work in this area may balance planning
optimal coverage paths with planning informative paths that encourage early exploration.

Multi-robotextensions: Whilewefocusonsingle-robotcoverageplanninginthisthesis,
many of these concepts can be potentially used to design planning and replanning algo-
rithmsformulti-robotcoverage. Forexample, onemaymodifytheMLC-Approxalgorithm
proposed in Chapter5to compute coverage subtours for a swarm of    n robots, instead of
a single tour.  For multi-robot coverage replanning, OARP-Replan may be modified to

                                                   106

===== PDF page 124; printed page 107 =====
replan multiple coverage paths at once, where any changes to the coverage ranks can be
addressedbyreplanningthepathsforasubsetofrobotsintheswarm. Apossiblechallenge
to address is to compute multi-robot paths with each robot being subject to a capacity
constraint, which may also be explored as future work.
    Another consideration when replanning coverage paths with multiple robots is respect-
ing communication constraints as determined by the swarm network.  Obstacles seen by
one robot in the swarm may affect a section of the path that was assigned to be covered
by other robots in the swarm.  In such cases, a replanning algorithm may additionally
re-assign sections of the path to balance the coverage load.
