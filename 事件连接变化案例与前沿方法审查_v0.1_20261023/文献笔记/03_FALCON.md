# FALCON 原文核读

核读日期：2026-10-23。题名：FALCON: Fast Autonomous Aerial Exploration Using Coverage Path Guidance。作者：Yichen Zhang、Xinyi Chen、Chen Feng、Boyu Zhou、Shaojie Shen。[作者v2](https://arxiv.org/abs/2407.00577v2)，初次预印本2024-06-30，v2为2025-05-16。正式刊物IEEE Transactions on Robotics 41卷1365–1385，[DOI 10.1109/TRO.2024.3522148](https://doi.org/10.1109/TRO.2024.3522148)。作者仓库BibTeX写2024，IEEE提交Crossref卷年为2025；精确early-access日未核实，不能仅按DOI含2024当卷年。保存核读20页作者v2，以下为PDF页码，不冒充正式版页码。

## 问题、输入与在线含义

§III（pp5–6）：有界未知三维空间、当前体素占据图、机器人位置/运动状态、有限视场前向相机。目标是快速探索并构建可达空间的体积地图，前沿不断变化是真在线地图发现；没有论证施工必检任务追加或任意动态障碍下的逐格责任。无前沿即结束，不要求指定基地返航。未知空间在全局代价估计里可带惩罚通过，不等于执行轨迹可直接穿越未验证障碍。

## 具体计算机制

§IV-A/B（pp6–7）：对地图更新包围盒涉及的粗格重新做连通分量标记，分开安全自由体素与未知体素，排除不满足安全距离的自由体素。用区域中心构建自由子图、未知子图及portal边；邻格间局部受限A*更新连接，孤立全未知组件排除。连通区域质心若不在区域内需投回区域，不可随意把质心当合法服务点。

§V-A（p8）：全局开放ATSP包括有前沿的活跃自由区和未知区，用短距离体素A*、长距离图A*估计连接与运动时间。它是**近似代价加速**，不声称长距离查询与精确最短路径等价；不能与旧LAST等价距离查询提速混称同一件事。

§V-B（p9）：保留远端区域的既定相对顺序，将当前位置和首区域附近的前沿视点插入，用SOP先后约束优化局部/区域间访问顺序；允许某些附近前沿延后访问，而非只完成最近区再去下一处。已存在的区域间矩阵元素复用。确有局部次序决策，不只是连接器，也不是只有算法名称的泛指TSP。§V-C（pp9–10）随后细化视点并生成轨迹，输出不等同ATSP估计路径。

## 作者真正比较的基线

§VII-A2（pp11–12）、表IV（p12）：NBVP、FUEL、RACER、ECHO、FAEP五个方法；Proposed为FALCON本身。RACER由作者改为单机器人；ECHO因作者称无公开源码而自行实现，不能说所有方法都原作者代码原封运行。TARE等相关工作不在这张主比较表。

§VIII（pp14–16）：UniDec、NoCG、CPAF、CPUN、NoSOP是模块消融，不是另五个外部前沿算法。NoSOP简化局部规划，仅考虑路径上的下一格；其结果支持本文场景内全局引导与局部先后约束的作用，不能直接证明我们的新增目标选择规则。

## 规模、计时和设备

§VII（pp11–13）：6个仿真场景、每方法每场景10次，尺寸从30×15×2米等2.5D办公室到30×15×15米三维Power Plant（表II）。共同最高速度2米/秒、加速度3米/秒²、80×60度视场、5米感知深度，900秒未完成则中止。Intel Core i7-13700F、RTX4090 24GB、32GB内存；规划器单核心，不能把有GPU机器误写为算法GPU推理。

§VIII表VI（p15）是计算时间：Complex Office完整配置总37.18毫秒，NoCG171.14毫秒；Power Plant完整86.21毫秒，NoCG760.28毫秒。表中Coverage Path和Local Planning列的加号分别列代价矩阵构造与求解时间，不是标准差；总时间另包括前沿识别、轨迹生成等。该消融中的图查询为**代价评估**，不用于生成实际执行路径（p15明确），不能当相同路线的等价加速证明。主表探索时长如Classical Office 98.0秒，是整个任务，与毫秒单迭代不同。消融Complex Office统计5次，不能偷换成主表10次。

## 保证、源码与适配边界

连通标记/SOP定义给出组件与顺序约束；未核到对本项目H、严格服务区、动态追加任务和基地返航的整体完备/最优定理。体积覆盖统计及重建质量不等于所有必检任务均合法采集。实际安全仍依赖占据图、轨迹模块和感知，不能移植为严格障碍面域保证。

[作者代码](https://github.com/HKUST-Aerial-Robotics/FALCON)，分支ros1-noetic，截止日最新核到提交312eb4d32c6c7af1a482f94a0a204aa2bb150cca（2025-05-16）；API原记录已保存。README描述Ubuntu20.04/ROS Noetic。本轮只读仓库及版本记录，无下载源码执行/安装。

与项目旧尝试的相似处：少量局部选择、保留远端结构、复用代价已有先例；不是给PPCPP多试入口后择短。SOP精确定义了局部插入怎样服从全局次序，但若仅将它接到旧P2/局部窗口，仍不能称原创。此处没有下视正方形必检责任、同一位置采集信用、历史免采、返航条件，需重建服务/顺序约束且去掉不适用的未知空间穿越估计；成本高。当前六例未证明需要其近似区域图，本轮不提出实现。
