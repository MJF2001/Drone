# 大型原始证据的无损归档

为避免 GitHub 普通 Git 单文件限制，新增文件中超过40 MiB的原件以gzip保存。原本地文件没有移动或修改；仓库中用此归档代替原始大文件。原始路径、长度、SHA-256和压缩文件名见manifest.json。

克隆后，在运行原实验包的只读verify前执行：

```powershell
python 同步大文件归档/restore.py
```

脚本校验字节数和SHA-256，再恢复原路径；已有同内容文件直接核验，有不同内容则停止、不覆盖。不调用任何规划算法。打包时所有压缩文件均已解压流式校验，与原件哈希相同。

完整证据=普通Git文件＋这些可还原归档。未还原时不应声称原封存目录完整。
