## 3. 新隔离原型的行为

- 新标识：`PPCPP_CORE4_INDEPENDENT_WRAPPER_v0.1_20261019`。
- 默认沿用权重(2,0.5)，随机种子保留作记录，既有核心决策仍为确定性。
- 完整契约、几何预处理、核心、返航、线性审核和截止检查计时；没有免费在线调权或从P2读取访问顺序。
- `route`仅包含截止前已审核合法核心；失败/超时为空，不输出未覆盖前缀作完整路线。
- 8项测试覆盖：核心合法、共同保底不可调用、改旧路线结果不变、核心恢复保留、截止不补救、非法核心拒绝、资源拒绝、输入不变及非法权重。部分测试合并多个断言，仍只算8项。
- 核心几何/奖励仍复用冻结实现；测试只能证明隔离行为，不能证明原算法保真、一般完备性、性能或对所有输入不依赖旧路线。未知异常保持显式抛出，正式运行器尚未实现。
