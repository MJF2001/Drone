## 4. 精确参照及其证明

推荐在完整可飞图上进行单位步长 BFS，状态为：

```text
(当前位置, 已采集的本次待检目标位掩码)
```

起点、当前位置采集、历史扣除、进入目标时更新掩码均需明确。终止目标为 `(基地, 全掩码)`。从该状态的最早到达距离得到最优步数 L*；父指针重建实际四邻接路线。

必须证明并测试：

1. 状态表示没有遗漏影响未来合法性或代价的信息。本轮目标只有步数，朝向只影响 PPCPP 决策、不约束精确路径；不加入转弯罚分。
2. 每条合法移动与状态转移对应，采集没有遗漏或虚增。
3. 所有边权为1，BFS 层序和访问规则保证首次到达终点即最短。
4. 无解只能在有限状态空间搜索完毕后声明。时间、内存或状态上限到达是 `unresolved`，不是无解。

每次精确查询预登记上限：60秒、最多800000个发现状态。记录发现/展开状态数、队列峰值、耗时、截止原因。不要为完成率提高上限重跑；实现错误修复需要独立版本及影响清单。

至少保存：输入哈希、实现哈希、最优长度、见证路径、搜索完成状态、资源统计及可复现命令。路径合法只是上界证据；最优性还依赖正确的穷尽/层序搜索，不能仅凭两个数字相等宣称证明。

## 6. 正式调用与核心指标

每个有效快照原 PPCPP 运行一次，采用既有20秒共同入口口径，保存完整 route/trace。PPCPP 为确定性实现，不用重复种子冒充更多样本；本轮不研究时间排名。

每个有效快照最多 **5次精确查询**，全部24快照最多120次；另有最多4次历史准备和24次事件后 PPCPP。门槛调用独立列账。

第一查询给出全局 L*。令原 PPCPP 长度为 Lp：

```text
绝对差距 G = Lp - L*
相对最优差距 = (Lp - L*) / L*    （L*=0 时单列，不除零）
```

只有最优已证明且 PPCPP 完整合法的配对进入差距统计。另列未解决、不可达、失败、超时、输入无效及分母；不能删去这些记录。

对两条路线按现有冻结指标口径补齐：覆盖率、暂缓、总步数、新采集、历史重复、本轮重复、非目标移动、90/180度转弯、完成覆盖步号、返航尾段。最优参照只优化步数，不能把任意一条最短见证的转弯数当最优转弯数。

## 7. 两项受控归因：不要同时开发多种改进

### 7.1 固定真实规划前缀，检查差距何时已经产生

从原版 trace 预先约定最多3个检查点：

1. 第一次恢复发起前。
2. 第一次恢复衔接结束后。
3. 第二次恢复发起前。

不存在的点标记“不存在”，重合点复用，不额外搜索其他恢复编号。每个点根据实际路线重新计算已经采集的目标，不能只信 trace 的计数。

令前缀走了 t 步，当前点为 x，余下任务为 U；精确求该状态完成覆盖返航的最短余程 V(x,U)：

```text
固定此前决策后最短总长 C_t = t + V(x,U)
此前决定已造成的最优差距 D_t = C_t - L*
后续原策略仍可改进的差距 R_t = Lp - C_t
G = D_t + R_t
```

所有项需查询完成才能报告为精确值；检查 D_t、R_t 非负，按时间顺序 D_t 不下降。

解释边界：

- 第一次恢复前 D_t>0，只证明在首次恢复之前已作出的决策限制了最优结果；不能直接认定某个奖励项错误。
- 恢复前后 D_t 增量表示这一整段固定衔接新增的损失，包含入口、路径及顺路采集影响，不能直接全部归给入口坐标。
- R_t 大说明该时点理论上还有空间，不表示现有三入口或任意实用算法能追回。
- 不以最优见证与原路线“第一次走向不同”判断损失；多个不同前缀可能都属于最优路线。

### 7.2 固定最后一个新采集位置，检查终点限制

取原 PPCPP 最后一个新采集目标 e。第5次查询求“最后一个新采集目标必须是 e，随后返航”的精确最短路线 L_e。

实现时禁止在其他待检目标尚未全部完成时首次进入 e；一旦进入并完成采集，允许沿任意合法路径返航。不要把“先采集 e，后来再经过 e”误当成最后采集位置为 e。空任务状态不适用。

检查：

```text
L* <= L_e <= Lp
固定该结束位置的代价 = L_e - L*
即使保留该结束位置仍可节省 = Lp - L_e
```

这说明结束位置限制的代价，不等于原路线返航尾段单独可节省的长度。该分解与前缀分解是两种重叠视角，不能把它们的“收益”再次相加。

本轮暂不做自由区域排序、局部奖励替换、后处理或入口—出口候选实现。若证据指向它们，只列为下一轮假设。
