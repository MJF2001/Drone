# 论文主题与具体研究问题

日期：2026-10-09。状态：用户已审核通过论文主题与问题定义；创新假设和效果仍待验证。此后不未经讨论扩大论文范围。

## 1. 暂定论文主题

**施工待检区域扩展与突发障碍条件下的无人机剩余覆盖路径重规划方法研究**

更短的工作标题：**面向区域扩展与新增障碍的无人机剩余覆盖路径重规划**。

英文工作标题：**Residual Coverage Path Replanning for UAV Inspection under Target Region Expansion and Newly Encountered Obstacles**。

标题中的施工场景用于限定问题背景；是否具有论文贡献，取决于方法与证据，不能仅靠换成无人机施工巡检应用来保证。

## 2. 用一段话讲清楚

无人机在已经发布边界的带状施工路面上进行覆盖巡检。在任务执行期间，待检路面可能沿直线或拐角扩展，也可能出现新的障碍，导致原来的剩余路线不再合适甚至无法执行。本研究利用已有覆盖进度、当前位置和当前公开环境，更新尚未完成的覆盖路线，在保证同等覆盖要求和通行、资源约束的条件下，减少完成剩余巡检的移动步数与路径代价。

## 3. 背景中的事实、假设和未知

| 层级 | 当前可以说什么 | 不能据此推导什么 |
|---|---|---|
| 项目需求 | 研究所任务要求施工边界内的自主巡检与动态避障 | 不代表一个人需要搭完视觉、飞控、平台和全部业务系统 |
| 本论文抽象 | 将环境变化约化为目标区域新增与通行障碍新增 | 不代表现场事件频率或形状已经实测 |
| 作业目标 | 完成规定路面的覆盖，降低移动代价 | 不代表新路面必须在几分钟内紧急检查 |
| 仿真证据 | 可检验算法在声明模型下是否有效 | 不代表真实施工现场已经验证、图像可识别或飞行安全已经验收 |

目前最需要验证的不是“牛耕式能不能覆盖”，而是**环境发生变化后，怎样更新已有覆盖计划比合理的简单策略更省路**。

## 4. 一个核心研究问题

> 当施工待检区域沿直线或拐角方向扩展，或出现新障碍物时，如何利用已有有效覆盖进度，从无人机当前位置重新规划剩余覆盖路线，在满足通行与资源约束、保留未完成覆盖任务的前提下，减少移动步数，降低完成剩余巡检的作业代价？

“有效覆盖”在本文第一版指按统一采集足迹规则获得的几何覆盖，不包含缺陷识别正确率。

### 4.1 子问题一：剩余工作怎样正确表示

区域扩展后哪些地面是真正新增任务？旧条带被障碍切分后哪些覆盖动作仍有效？已有覆盖如何保留？哪些未完成目标只是暂时不可达？

需要产出一致的状态和更新规则。这是研究成立的基础，但“设计覆盖账本”本身不自动构成创新。

### 4.2 子问题二：更新多少路线才划算

只绕过局部障碍可能保留了不合理的访问顺序；把全部剩余路线重算又可能增加计算量，并破坏原来合理的衔接。

应研究事件对剩余区域连接、条带入口出口和访问次序的具体影响，再判断局部更新还是较大范围重排更合适。**目前不预设局部修补一定更短，也不预设全量重算一定更慢。**

### 4.3 子问题三：收益在什么条件下存在

直线扩展、拐角扩展、近处障碍、远处障碍以及不同已完成比例，可能产生不同结果。需要识别优势范围、退化情况和失败原因，而不是只报告一个平均提升比例。

以上三个子问题围绕同一个核心问题，不拆成三套独立研究系统。

## 5. 最小问题定义

在事件公开时刻t，输入当前位置x(t)、剩余资源e(t)、待检区域R(t)、允许通行地图F(t)、已完成覆盖C(t)以及原路线剩余部分P(t)。

剩余目标为：

```text
U(t) = R(t) − C(t)
```

输出从当前位置出发、完成U(t)并按约定返航的合法后续路线。固定足迹与采集规则由所有算法共同遵守。

在可行场景中，主要目标为最小化后续移动长度；整轮在线实验比较总移动长度。可写为：

```text
minimize L(P)
subject to:
  规定剩余目标达到统一覆盖标准
  路线在当前允许通行空间内
  动作连续且不穿越障碍
  资源消耗和返航要求合法
```

在线算法只知道当前已公开信息，不知道将来是否扩展、扩展到哪里以及未来障碍的位置。因此不宣称能够获得整个未知事件序列下的全局最优路线。

如果新障碍导致目标无法覆盖，应报告不可行与未完成量，不通过删掉目标让问题表面完成。

## 6. 主实验假设

1. 单无人机，二维固定高度规划，带状目标可以直行或转角。
2. 初始待检边界已知；新增边界在事件公开时才已知。
3. 新障碍在公开后为分段静态，不研究连续运动预测。
4. 主实验通过公共地图更新提供环境变化，不研究视觉误检与定位误差。
5. 采集尺度、覆盖标准、信息时序、资源规则对所有算法一致。
6. 保留覆盖进度；已覆盖区域在合法情况下仍可作为通行空间。
7. 初步实验使用有限事件流，明确何时停止新增事件并检查最终完成。

这些是假设范围，不是真实施工环境的完整描述。后续若引入局部感知、三维可见性或换电，需要另行判断是否仍适合本篇论文。

## 7. 与邻近问题的区别

| 邻近问题 | 本文的区别 |
|---|---|
| 静态已知地图的牛耕覆盖 | 执行中目标集合或通行图发生改变，需要从当前状态继续 |
| 固定未知地图的探索覆盖 | 本文允许待检目标真正新增，不仅是原有环境逐渐显露 |
| A*或D*的点到点重规划 | 本文必须决定剩余覆盖动作及顺序，不能只找到去一个终点的路 |
| 外卖配送或复检点调度 | 主任务是具有空间范围的覆盖，不是带期限的已知点配送 |
| 实时动态避障控制 | 本文研究公开障碍后的覆盖路线更新，不研究连续避碰控制器 |
| 图像质量与缺陷检测 | 本文使用统一几何采集模型，不训练视觉网络 |

## 8. 目前最接近的文献给我们的限制

2026年的[TRACE](https://arxiv.org/abs/2609.21777)已经讨论剩余未覆盖空间的连接变化，以及保留未变化区域顺序的增量路线更新。因此不能把“保留进度、只改受影响部分”直接当成新贡献。

[OARP-Replan](https://arxiv.org/abs/2311.17837)已经研究未知静态障碍中断覆盖路线后的限时重规划。因此“发现障碍就重算路线”也不是新的问题表述。

我们需要核对这些方法对真正目标扩展、拐角接入和新障碍插入的处理范围，再寻找具体不足。**目标扩展与障碍组合是研究入口，尚不足以证明方法新颖。**

## 9. 可以检验的假设，不是已经确定的创新点

| 假设 | 怎么验证 | 什么结果会推翻或削弱它 |
|---|---|---|
| 有些事件只需更新少量路线即可保持较好效率 | 与全量剩余重算、强文献方法比较 | 路线明显更长且计算收益很小 |
| 拐角扩展需要重新考虑剩余条带的衔接 | 对照简单尾部追加与重新排序 | 简单追加在多数合理场景中已足够好 |
| 障碍改变连接关系时，固定原顺序可能产生无效绕行 | 构造并统计不同拓扑影响等级 | 强局部修补已经消除绝大部分浪费 |
| 可利用结构特征选择重规划范围 | 分析事件类型与收益，做选择机制消融 | 规则不稳定，换测试集后失效 |

只选证据最充分的一条继续形成方法，不要求四条都成为算法模块。

## 10. 一篇可投稿论文需要达到什么程度

至少需要：

1. 一个明确、不过度扩张的问题模型。
2. 对最接近方法的准确分析，不能仅与朴素牛耕式比较。
3. 一个具体可复现的方法改进，说明为什么有效以及额外代价。
4. 同信息、同目标、同预算条件下的对照实验。
5. 无变化、单事件和组合事件测试，以及参数敏感性、消融与失败分析。
6. 对适用范围和仿真限制的诚实表述。

若主张完整覆盖或复杂度优势，需要对应证明或限定性的论证。有限样例全部通过不能代替任意环境的理论保证。

没有真实无人机仍可开展算法研究，但不能保证某个档次的期刊一定接收。仿真论文更需要问题合理、强基线、可审计实现和清楚的算法贡献。

## 11. 当前判断与确定性

| 判断 | 确定性 | 理由 |
|---|---|---|
| 研究范围已足够明确，可以建立最小仿真闭环 | 高 | 两类事件与一个主要目标已经收敛 |
| 现有A*可以作为连接工具，不能单独作为覆盖强基线 | 高 | 点路径与覆盖决策解决不同问题 |
| 最接近的近年工作必须纳入比较或充分讨论 | 高 | 已检索到直接重叠的方法机制 |
| 新方法能显著降低总代价 | 低 | 尚未实现并与强方法公平比较 |
| 场景参数代表真实施工现场 | 低 | 没有现场统计或实机采集支持 |
| 该方向一定形成足够的发文创新 | 低 | 需依赖文献深读与实验发现，不能提前承诺 |

## 12. 接下来该做什么

先用最小例子固定覆盖规则、事件与完成条件；并行的工作内容是精读TRACE、OARP-Replan和C*，建立原假设与本问题的差异表。这里的“并行”指推进顺序可交错，不要求额外人员或代理。

先实现两种透明工程基线，再确定一项最相关的文献方法做严格机制核对与动态适配。通过失败案例决定改进点，最后才确定正式论文的创新表述。
