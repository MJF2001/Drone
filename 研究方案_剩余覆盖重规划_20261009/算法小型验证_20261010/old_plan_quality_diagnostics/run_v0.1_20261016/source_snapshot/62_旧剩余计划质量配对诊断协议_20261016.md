# 旧剩余计划质量配对诊断协议

日期：2026-10-16。本协议在产生新参考路线和求解结果前保存并哈希保护。第58份之后的有限开发诊断A，不是正式留出主实验，也不替代尚未完成的接口/外部顺序实验B。

## 目的与唯一改变变量

第58份的12个无变化控制保留原扫描尾段时，20秒均长于强P2。先检验这种损失是否依赖旧剩余计划质量：同一快照仅将old_route替换为在其当前公开地图上20秒P2生成的合法参考尾段。当前位置、真实覆盖历史、自由空间、目标、基地、资源上限、初始目标和配对种子均保持不变。

RAW为原扫描尾段，P2_REF为优化参考。P2_REF是人为构造的检查点反事实尾段，不是重新生成整轮执行历史，不能称初始任务就使用强P2或代表真实施工。其生成用无变化状态，不读任何事件几何/未来障碍；它可能得到保底，不能根据改善幅度筛掉地图或追加准备预算。

## 输入与运行矩阵

只使用已归档range_diagnostics/inputs_v0.1_20261015的families所列12个control。12地图均纳入，不挑正反例；没有新增独立地图，不生成留出几何。

1. 参考准备：12状态×P2_MULTI×20秒×一个既有配对种子，共12次独立求解，保存所有路线、来源、耗时、失败与超时。
2. 主配对：12状态×两种old_route（RAW、P2_REF）×两方法（KEEP_EMPTY、P2_MULTI）×1/20秒×一个种子，共96次独立执行。
3. KEEP_EMPTY使用既有road_range_candidate的R_SEED，无事件时切口必须是(0,0)、required为空。它仍计共同保底、结构分析、完整路线审计；核心即旧尾段，最终可能选共同保底，二者分开。
4. P2_MULTI使用冻结入口。其共同保底也读取old_route，因此两种参考分别运行，不免费复用之前成绩。

共108次规划调用，准备12次与主配对96次分开统计，不混入原200次。本轮不增加事件状态、范围层数、种子、参数或新算法；96次完成即停。发生错误保留失败批次，不原位覆盖或择优重跑。

## 预算与公平性边界

主配对每次从零开始总软预算1/20秒，独立进程/缓存、串行执行；方法和参考顺序按地图循环反向、预算交替，固定在线程环境请求1。看门狗budget+30秒只作故障兜底。

参考准备的20秒不是免费在线时间，也不是精确最优证明。P2_REF组共有额外的离线参考生成开销，本轮仅作条件质量敏感性诊断；**不得把P2_REF保留成绩与RAW整体P2成绩包装成同预算算法优势**。同时报告每张地图准备耗时，若讨论联合成本应把准备计入，不能只报保留阶段。

全量准备、范围分析、保底和候选验收沿原统一计时；保存后独立审计在外。超过软预算10ms全部保留，不称硬实时。

## 开跑前与结果验收

先核对原输入清单/冻结源码/profile哈希。逐输入证明：role=control，event=no_change，targets=initial_targets，旧路线覆盖当前剩余任务并返航；独立结构重建证明空窗口。

产生参考后，另一套逐格检查验证起点、四邻接、自由格、覆盖和返航/资源；对RAW/P2_REF逐键比较，只允许old_route不同。原route、准备任务来源、准备路线哈希与新输入哈希均存档。

96条最终路线与存在的KEEP核心路线独立复核；KEEP核心必须逐点等于该组old_route、空局部patch为当前位置，所有接受时刻在预算内。对返回路线重算步数/覆盖、最终来源、软超时，记录无输出/异常/看门狗，不删除失败。

## 预定统计和解释

两预算分别报告：每种参考下KEEP/P2的短平长、总步差、地图等权相对差，以及每方法RAW→P2_REF的配对变化；准备耗时单列。每地图一个状态，一次种子，12地图内部有共同生成结构，不作显著性或泛化断言。

主问题为优化参考下的保留损失是否仍存在：

- 若损失大幅缩小，说明第58份无变化反例对原扫描质量敏感，但不能解释事件状态全部损失，也不能证明固定接口无问题。
- 若仍存在明显损失，说明20秒可行参考仍可能进一步优化；不能将P2_REF叫最优、把有限搜索差距归为单一因果。
- 同一P2获得更强old_route后改善，是保底/初始化依赖，不是新算法贡献。
- 没有事件时窗口为空，接口与外部顺序未释放，因此本轮不能单独回答这些限制过强与否。后续B需另写协议，以同一旧参考和任务责任集合只改变约束。

冻结基线不改；当前无确认主算法或创新。无论结果正负均归档停止，不看结果追调20秒参考、阈值或样本。
