# 机制对照预设（2026-10-10，执行前）

本轮仅做诊断，不选论文赢家，不把实验后发现当预先假设。

1. 输入固定为run_07的32个公开快照。保留2个不可行输入并报告。每个快照只执行一次，不作可靠计时比较。
2. 分组实验G：按未完成目标连通分组，组内使用共同H方向采集位置；固定点集和组顺序初解。自由排序G_free与组连续约束G_locked使用相同初解、四邻接A*距离、最多8轮最佳改进2-opt、5秒上限。约束版只接受组连续的候选；不冻结组内方向。无独立留出集。
3. 旧段实验S：相同旧直线包与H方向新增单点包，相同有序点实例（含重复坐标），同一初解；S_free允许任意2-opt，S_locked要求每包连续且包内为原顺序或完全逆序。不能跨实验G/S比较点集效果。两者共享初始可行解与搜索规则。
4. 所有排序实验严格访问全部规定点实例（沿路仍记录覆盖）。这是隔离排序约束的诊断目标，不等同于P1—P4的完整算法性能。另对同一最终顺序用共同expand跳过已无采集价值的访问，报告步数变化，检查执行层跳过规则的影响。
5. 启发式自由版虽然可行解空间更大，有限2-opt仍可能更差；不得称任何版本最优。报告A*距离代理目标和实际路径长度，不把途中覆盖的收益混同于排序代价。
6. 采集/飞行空间敏感性：只运行P2，在原有30个可行输入上组合radius=1/2、margin=1/2/3。当前目标、事件障碍和历史实际运动不变；按同一历史前缀及各radius重新计算旧目标覆盖，新目标不追溯计覆盖。飞行域按扩展后目标膨胀，并明确添加基地入口(1,3),(2,3)；若当前位置不合法报告不兼容，不迁移当前位置。每种配置单次执行，仅诊断。更改足迹会改变历史覆盖量，不称纯粹只变算法的对照。
7. margin扩大后有些原本横贯margin=2通行域的墙可能被外绕；这是模型假设的影响，必须披露。radius=2只是未标定理想5×5足迹，不能当真实相机参数。暂不采用radius=0，以免把保留的障碍下目标直接改成无可观察的格点访问问题。
8. 保存输入、所有路线、审计、超时和失败，源码归档。机制对照和敏感性中均允许报告不支持原想法的结果。下一步是否采用该机制取决于统一条件的证据，不为了偏好某方法修改地图。
