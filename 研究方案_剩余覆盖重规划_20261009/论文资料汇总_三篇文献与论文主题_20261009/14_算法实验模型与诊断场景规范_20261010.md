# 算法实验模型与诊断场景规范 v0.2

日期：2026-10-10。状态：本轮探索实验采用的明确模型，不代表已验证的现场条件，不改动用户已审核的02号论文主题。后续修改规则须登记，旧结果不得混算。

## 1. 核心问题保持不变

单无人机执行施工路面覆盖期间，待检区域真实扩展或新障碍公开，从当前位置、实际覆盖进度和旧剩余路线出发，更新剩余覆盖路线并返航，减少移动步数。本轮不研究视觉、调度、三维避碰控制或实机能耗。

## 2. 三种空间必须分开

| 符号 | 含义 | 本轮规定 |
| --- | --- | --- |
| D | 获准飞行的水平位置集合 | 事件前明确提供；本轮事件前后固定，不由新增待检区域自动膨胀 |
| T_t | 截至时刻t已经发布、需要检查的地面 | 直线/拐角扩展时增加；未来待检区域不提前作为任务提供 |
| B_t | 当前公开的飞行禁入格 | 障碍事件增加；合法位置F_t=D−B_t |
| C_t | 已发布地面中已被有效采集的目标格 | 只按实际历史运动及当时公开的T累计，不由规划路线预测充当完成 |
| K(x) | 位置x的理想采集足迹 | 固定3×3正方形，Chebyshev距离≤1；沿每个实际合法格点采集 |

剩余目标U_t=T_t−C_t。覆盖是K(x)与T_t的交集，不要求无人机逐个飞到目标格中心。T_t与F_t不混为一个集合；障碍不自动删除目标。

**固定D不表示知道未来目标。** 允许知道施工场地里哪些位置获准飞行，但不知道哪些位置将来会成为新增检查任务。狭长飞行域可能透露场地形状，这是明确给予所有算法的先验，不宣称未知环境探索。D由场景生成器独立定义，不传给算法未来任务序列。

## 3. 边界扩展的语义

本文研究的是待检目标边界T扩展，不默认电子围栏D同时扩大。若现场需求以后确认是二者同步改变，应作为另一类明确输入规则，不能与本轮固定D成绩混用。

举例：场地允许飞行范围已知，原来只检查已发布的前段路面，新增完成路面公开后加入T。无人机可以已飞过尚未成为目标的位置，但在发布前不记为该新增路面的检查完成。

本轮仅一次事件或同一时刻的扩展加障碍组合，不称连续在线事件实验。多次事件实验需明确各算法执行造成的状态差异和公共事件时钟，稍后单独做。

## 4. 障碍和覆盖能力的边界

本轮B是二维飞行禁入区域的代理，不提供实体高度、相机可见性或遮挡模型。因而数学上可能从旁边足迹覆盖B中的目标，但不能解释为“相机看穿机械或看见箱子下路面”。

当前模型适合检验禁入区域引起的连接/覆盖决策变化，尚不足以声称已仿真所有实体施工障碍。后续若讨论路面遮挡，必须另提供可观测关系或未完成目标状态；不得为了完成率把障碍内地面删掉。

给定模型下：若基地不在当前位置可达分量，或某剩余目标没有任何可达采集位置，则报告环境不可行与未完成目标。算法没找到预算内路线不等于环境不可行。

## 5. 动作、目标与资源

- 四邻接单位移动；当前快照求解期间位置固定。本轮不宣称实现边飞边算。
- 返回统一基地；合法穿过已检查地面，全部移动计步数。
- 可行路线以完成全部剩余覆盖并返航为前提，主指标为剩余路径步数。缺覆盖路线不能因短而获胜。
- 距离预算为4×|D|，同快照所有方法相同，事件前后固定。只是宽松的归一化限制，不对应电池容量。时间上限5秒；首次可行解生成和预处理计时。
- 求解器只接收当前F、T、C、位置、基地、旧路线与预算。场景元数据及未来事件不传入。

主结果暂用固定3×3足迹。5×5和通行余量变更只属于模型敏感性，不混入方法平均提升。

## 6. 新诊断集的生成规则（运行前确定）

本轮地图和算法全部为探索用途，不是独立留出集。

| 维度 | 固定规则 |
| --- | --- |
| 初始路面 | (3,3)起始的水平矩形，尺寸18×6、24×9 |
| 公开飞行域 | 两类：宽矩形场地；固定狭长L形飞行走廊。各自独立生成并在所有事件中保持不变 |
| 初始路线 | 事件前在共同D上用既有P2生成，供所有方法共同执行；失败则记录生成失败，不换有利路线 |
| 事件进度 | 已覆盖旧目标比例首次达到25%、75%时，记录实际位置和历史前缀 |
| 无变化 | 完整负对照 |
| 直线扩展 | 初始路段右侧增加9×路宽目标 |
| 拐角扩展 | 右侧加路宽×路宽转角连接块及向上路宽×9目标 |
| 近/远局部障碍 | 在旧后缀约15%/70%路径位置附近放置2×2禁入块；若占当前点/基地则按固定顺序寻找下一个候选，不看任何算法结果 |
| 通道障碍 | 初始道路约2/3长度处放一格宽横断禁入列，只保留该列最低合法位置作为通道；当前点冲突时按声明顺序平移 |
| 同时组合 | 直线扩展+通道障碍，拐角扩展+通道障碍 |

共2个尺寸×2类飞行域×2个进度×8类事件=64个快照。禁止按算法胜负筛选地图。记录实际剩余连通块数、旧路线是否失效、基地/目标可达性、障碍是否切断通行图等结构信息；所有不可行案例仍保留。

本轮以P1/P2检查模型与强弱参照，不新增候选算法，不因P3/P4此前不占优继续调其参数。每个快照各执行一次；单次时间只记录，不作可靠速度排名。使用相同旧可行后缀候选、连接器和独立审计。

## 7. 生成实现必须通过的检查

1. 同一尺寸、飞行域下所有事件D完全相同；旧目标、初始执行和旧后缀一致。
2. 初始及新增目标均在预先声明的D里；障碍不在事件时占据当前位置或基地。
3. 历史覆盖必须重放共同前缀确认，不给新增目标追认覆盖。
4. 路线失效与环境不可行分开记录；每条完成路线独立核查覆盖、移动、返航和预算。
5. 狭长场地的形状是公开空间先验，不被包装成地图未知探索。

## 8. 这些规定解决了什么，尚未解决什么

解决：目标扩展时合法飞行空间是否暗中改变、障碍下目标是否被静默移除、初始历史是否对所有方法一致、成绩是否靠删目标获得。

尚未解决：真实图像识别条件、格长与相机参数对应、物理遮挡、真实资源模型、连续事件与飞行中计算、最终算法创新。固定D只是本轮可审计的实验假设，不自动成为真实施工规律。
