# 固定采集位置精确排序参照与判断

日期：2026-10-10。承接15号报告。探索性小规模诊断，不是面积覆盖最优求解器，不是创新算法或正式性能确认。

## 1. 先说结论

**这轮不支持继续把“换一个更强的TSP排序器”作为主要改进方向。** 在可精确检查的小点池上，启发式多数已经达到指定点访问距离的最优值；把本轮得到的精确访问顺序加入P2候选，没有改善完整覆盖路线。

但也**没有证明P2已经是面积覆盖最优**。精确问题强制访问给定采集点，原问题只要求覆盖地面，可以利用沿途采集或改选采集位置，两者目标不同。

## 2. 精确求解的到底是什么

固定当前地图、起点、基地以及一组采集位置，要求每个位置都访问一次或至少经过一次，位置间按当前地图最短距离连接，求总访问距离最小的顺序。允许路径经过已访问位置；点之间的最短路通过现有A*获得。

用子集动态规划计算：

```text
DP[S,j] = 从当前位置出发，已访问指定集合S，最后到达j的最短访问距离

DP[{j},j] = distance(当前位置,j)
DP[S,j] = min_i (DP[S−{j},i] + distance(i,j))
最优值 = min_j (DP[全部指定点,j] + distance(j,基地))
```

固定起点和基地，递推枚举所有子集和最后位置；只有完整算完才报精确值。复杂度为O(n²2^n)，本轮预先限制完整点池不超过14点，单池30秒上限。没有截取大点池的前14点，没有删除覆盖目标。

该算法只是诊断工具。精确参照使用额外离线计算，不与P2的5秒求解上限作速度竞争；也不能称为原覆盖问题的下界。面积覆盖最优路线可能根本不访问某些指定采集位置。

## 3. 使用哪些实例、怎么公平比较

使用run_11全部64个快照，各自用共同H/V生成器得到两个完整采集点池，共128池。每池保留P2原有四种顺序：蛇形、最近邻、蛇形经8轮以内2-opt、最近邻经8轮以内2-opt。

比较分两层：

1. **固定点池访问目标。** 取四种启发式中的最小距离和，与该池精确值比较。
2. **实际仿真覆盖目标。** 对每个顺序独立执行沿途采集和跳过无采集价值访问，审计完成覆盖并返航的实际路线；比较精确顺序与该池启发式的最佳实际长度。

完整P2还会比较H/V两个池以及合法旧后缀，因此单池的改善未必改善完整P2。

提取候选时保持P2原始几何调用顺序，未插入额外距离查询；其最佳实际长度与run_11原P2结果在64个快照上全部一致。规范化执行时，每条顺序从新的A*缓存开始；重新评分后，完整P2候选最佳长度也与原结果一致。这避免把缓存里的等长路径选择变化误说成排序改善。

协议在运行前保存在[EXACT_ORDER_PROTOCOL.md](../算法小型验证_20261010/EXACT_ORDER_PROTOCOL.md)。本批仍是探索集。

## 5. 更短的指定点访问，未必带来更短的覆盖

将一个精确最短访问顺序按共同采集规则执行，与同池最佳启发式实际路线比较：

| 精确顺序实际展开后的效果 | 点池数 |
| --- | ---: |
| 更短 | 2 |
| 相同 | 60 |
| 更长 | 2 |

两个更短案例均为18×6、75%进度、拐角扩展加通道障碍的H池：分别从92降到86步、84降到78步。但相应V池启发式本来就能达到86或78步，因此没有改善完整P2。

两个更长案例是18×6、25%进度、近处障碍的H池，宽场地与走廊各一例。以宽场地为例：

| 顺序来源 | 必须访问全部指定点的距离和 | 沿途覆盖、跳过无价值访问后的实际步数 |
| --- | ---: | ---: |
| 蛇形初解 | 68 | 36 |
| 蛇形经2-opt | 42 | 42 |
| 本轮选出的精确访问顺序 | 38 | 38 |

这不是数值矛盾：蛇形执行过程中已经完成一些后续位置的覆盖工作，因此能跳过它们。访问距离和却仍将这些位置当作必须访问的任务。2-opt把访问距离由68降到42，却失去了原顺序下可以省掉访问的效果。

P2保留并按实际路线评分多种初解，所以本例仍能选36步路线，没有被较差的改进顺序替代。

精确访问问题可能有多个同价最优顺序，本轮只取确定性的一条，没有枚举所有同价最优解。因此不能说“所有最优访问顺序的覆盖表现都更差”，只能说优化访问代理目标本身不能保证实际覆盖收益。

## 6. 对完整P2有什么影响

把所有可精确池的精确顺序加入原有规范化候选，32个可精确检查的快照没有一例得到更短的实际路线。其余32个没有精确候选，不计为证实无改进。

因此，此次结果支持：**在本批可精确检查的小规模案例上，继续强化固定点排序没有给完整P2带来收益。** 不支持：P2面积覆盖已最优、所有地图都无需改善排序、所有精确最优访问顺序都无价值。

## 7. 独立判断与下一步

我建议暂时不换更复杂的TSP求解器，也不把“排序求得更精确”当论文贡献。当前更需要分清下面两件事：

- **采集位置选得是否合适。** 当前H/V生成器只提供很少的点池；点池内最优，不代表选点本身合适。
- **排序代理是否忠实于覆盖作业。** 当前2-opt按访问距离改进，而最终按沿途覆盖执行。已经观察到二者不一致，但完整P2的多初解已抵消本轮负面案例，尚不能据此宣称一定存在可观收益。

下一轮应做一项有限对照：固定排序器，改变采集位置生成的起始偏移，观察实际路线是否稳定改善；原位置候选保留、统一求解预算，不能因为增加候选后挑出更好结果就称算法创新。若有空间，再做单机制解释；若仍无明显空间，应停止继续堆叠自造原型，转向规范文献方法对照并重新判断研究切口。

本轮没有检索新的创新性证据，没有认定上述两点是文献空白。后续若决定围绕选点或覆盖感知评价设计方法，必须核对最接近工作，不能仅凭此处的失配例子保证可发表性。
