# 障碍出现后是否需要引入 C* 的机制验证

本轮结论：连接路径被阻挡但采集位置仍有效时，现有 A* 与任务排序足以处理本实验案例。采集位置失效时，需要更新采集对象；可以在现有 A* 与 TSP 外增加局部采集位置修复，无须由本实验推导出必须采用完整 C*。

## 验证性质

这是独立的、可重跑的简化机制实验，使用真实项目 A*，但不是现有系统整体运行结果，也不是 C* 与 A* 的性能对比。没有修改原算法、执行长训练或读取未来事件。两组在一次地图更新公开后，从相同位置和已采集进度开始，重新规划剩余任务；没有模拟发现延迟、紧急制动或运动中途地图更新。

## 现有代码检查

learning_branch_20260908/src/r1a_protocol/environment.py 中的 TaskSpec 以位置、服务时间表示任务，astar_path 提供四邻域最短路径。_solve_local_fine_route 对小规模精检组穷举顺序，包含返航距离；已有任务排序功能。该模块不包含第41版完整的道路块有效成像覆盖几何。

第41版已经设计进度保留、质量不合格留账、补采关联原任务。因此不能把未完成管理说成原方案没有。本实验只是将相关几何条件具体化，不评价上层任务账本优劣。

## 公平比较设置

- 11×8飞行栅格，已知道路边界内54个地面采样单元。原有6个3×3成像位置，第一张已完成，保留9格进度；当前(2,2)，基地(0,0)。
- 第一组保留可达的原采集位置，更新障碍地图并重新排序；不可达任务保留责任，不伪报完成。第二组同样处理，再用确定性贪心覆盖规则添加能补齐缺口的位置。
- 两组均调用项目原始A*，并采用相同的固定起点、返回基地的精确TSP动态规划排序。没有用较差排序器故意削弱基线；这也不等于复用了生产调度器的全部行为。
- 航程只统计地图更新后的剩余路程，拍摄次数不含共同完成的第一张。采集服务统一按每张1个抽象时间单位另行记录，没有宣称真实秒数或能耗。
- 只在指定位置拍照，不把转场经过自动当作有效采集。连续拍摄场景需另测。
- 飞行禁入和图像遮挡是独立层；禁入格可以代表航点不可用，但本简化相机允许邻位覆盖其对应地面。若实际物体同时遮挡路面，需要加入遮挡模型，不适用这里的可补齐结论。
- 成像是地面栅格集合模型，没有标定真实相机、分辨率、视线、姿态和重叠质量。所有飞行格视为已包含必要安全边界。

## 结果

|场景|只更新路径：有效覆盖|增加位置修复：有效覆盖|剩余航程|剩余拍摄次数|
|---|---|---|---|---|
|无障碍|54/54|54/54|22 → 22|5 → 5|
|仅连接路径绕行|54/54|54/54|28 → 28|5 → 5|
|1个采集位置失效|45/54|54/54|22 → 24|4 → 6|
|2个采集位置失效|36/54|54/54|22 → 28|3 → 7|
|区域被完全隔断|36/54|36/54|16 → 16|3 → 3|
|持续图像遮挡|53/54|53/54|22 → 22|5 → 5|
|可达定点复检|1/1|1/1|22 → 22|1 → 1|
|不可达定点复检|0/1|0/1|4 → 4|0 → 0|

另做30个固定种子障碍布局，每个布局成对设置“障碍不占采集位置”和“额外使一个采集位置失效”，共60例；加上述8例，总计68例。

30个仅转场受影响案例，两组输出完全相同。30个位置失效案例，固定位置组覆盖率均为45/54（83.33%），修复组均为54/54。其平均额外航程为3.60格。

这些随机例的83.33%由不重叠的6个原始成像块和1个位置失效这一构造决定，不是从现实数据估计的平均漏检率，也不能据此声称泛化显著性。第二组补齐更多工作，航程更长并不代表更差；第一组路程短也不能称为更高效。没有进行同等完整覆盖下的算法最优性比较。

## 审计

68例均通过：A*距离与独立BFS一致；执行轨迹不穿越阻塞格、相邻步合法；任务序列含返航；既有覆盖不丢失；残余缺口留账；修复组覆盖达到本候选位置集合当前可观测的范围。TSP不超过6个位置时还用全排列独立核对最优路程。不可达/遮挡案例不将分母缩小来伪造100%。源代码SHA-256记录在results.json，生成报告时重新核对一致。

## 对方案的具体建议

1. 保留现有上层账本、A*和任务排序。
2. 障碍公开后先判断影响类型：仅路径受影响、原采集位置失效、或成像被遮挡。
3. 仅路径受影响时更新A*代价；位置失效时依据剩余有效覆盖范围选择替代位置，再交给已有排序器；无法补齐时保留未完成责任。
4. 本实验没有验证C*覆盖图比现有结构更省路、更快，也没有验证航段拆分、条带恢复或三维动态避障。若要比较C*，下一轮必须统一信息公开时机、相机模型、候选位置、边界和任务完成口径，不能直接比较原复现的未知环境圆盘覆盖与本实验的定点拍摄。
5. 目前支持的是一个小型位置修复模块的必要性条件；不支持为了该功能将整个执行层替换为C*，也不能作为论文创新性证据。
