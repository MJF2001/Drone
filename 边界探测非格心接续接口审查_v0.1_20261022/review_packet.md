# 负责人审核入口：v1.2只读接口审查

本包由最新v1.2授权产生，替代旧稿的高处观察/双来源内容；没有模型实现或实验。原目录在开始前不存在；未覆盖历史结果。推荐A仅为有条件设计建议，未替负责人选择参数或冻结协议。

建议阅读顺序：

1. [通俗结论](00_通俗结论.md)：能说什么、两个重要旧合同差异、停止状态。
2. [真实接口约束](01_真实接口约束.md)及[源码索引](源码索引.md)：源码路径/行号/哈希，已有连续执行器证据。
3. [模型账本与时序](02_模型账本与时序.md)：任务公开与障碍探测分开，未知与安全分开，实际H/距离/等待分开。
4. [两方案及代价](03_两种接入方案与代价.md)：推荐计费连接，严格真实相邻尾段、不伪造方向；入口选择与额外路程需审。
5. [10项待裁决与18项纸面门槛](04_待裁决与有限纸面门槛.md)：全部未执行，无新输入/参数值/调用额度。

核验材料：执行依据原字节、18份源码逐行文本、来源hash、历史源一致性、根进度前后快照、零调用账、completion_manifest、final_receipt。历史字节一致性仅证明选中来源未变，不证明整个工作区全部文件未变或新语义已验收。

安全复核命令（PowerShell，工作目录为项目根目录）：

```powershell
& '.\运行环境\python\python.exe' -B -X utf8 '.\边界探测非格心接续接口审查_v0.1_20261022\verify.py'
if ($LASTEXITCODE -ne 0) { throw '只读文件核验失败' }
```

verify只读取文件、计算SHA256、对比文本/账本，并以AST查看本包两个工具的导入名；不导入或调用生产源码，不重放路线，不做几何、图搜索、桩或门槛测试。不要运行历史验收器代替本包verify：历史verify可能带BFS/几何调用。根进度以后若合法追加，最后一项实时根进度哈希会变化，应按保存的执行后快照核对历史版本，不改历史manifest。

交付决定：封存停止，等待负责人裁决D01—D10。本轮不自动开始适配、参数选择、正式比较、正线段缓存或信用筛选；没有推送或发送其他线程。
