# 最小执行器纯桩合同

本目录只使用手写小图、手写完整路线和模拟入口耗时。A/B是桩方法名字，不是原PPCPP/P2；所有技术轮次累计stub响应上限48，固定本次计划43，最多三技术轮次。不导入真实算法，不生成覆盖路线，不评价性能。

执行稿三项裁决直接采用：共同整数tick、规划暂停世界；同一外生事件表，不按方法开路；完整合法返航且严格entry_seconds<20才准入，无外层保底/重试。未来真实接口未连接。

每个tick的边界先发布全部同tick事件（按ID排序），P只增/F只减；处理current/base占位，再对合法current给一次当前公开目标信用，再检查活动任务/基地可达。初始或发布点至多一次响应；最后发布后若已在基地且U空，直接成功不多求解。获准计划至多执行一格；到达t+1先按移动前地图记信用，然后t+1事件生效。到T_max只可判已到达成功，否则tick_limit，不开始新移动。等待推进tick、保留previous、不扣距离。

H保持真实信用；U=(P∩F)−H、D=P−F−H、E=E0−M。initial_targets=P_before∪H，包含发布处的新起点信用。首次old_route=[current]；以后为本方法原计划从游标起的字面后缀，即使事件后非法也不修补。当前plan和游标只有获准新响应时替换。未执行的完整计划长度/废弃尾段不计移动。

回调只收UTF-8 JSON bytes，字段在contracts.SNAPSHOT_KEYS固定。name固定stub_snapshot，避免透露世界/夹具/方法/未来ID；不包含未来事件表、T_max、最后发布标志。回调返回route、entry_seconds及原生状态；原生deadline本身不替代外层准入。真实算法今后须另做字段规范和单点old_route等兼容验收。

分类保存environment_termination（占位/可达性）、deadline、invalid_route、resource_infeasible、solver_no_solution、technical_error。无合格响应不执行第一步、不用旧计划替代。失败方法H/移动/方向冻结，公共世界继续发布到最后，最终分母保留。技术异常停止批；预期NaN拒绝安排为最后子例，保留technical_error后不再有stub调用。

四类实际移动为fresh_target、initial_historical、session_repeat、non_target；当前全部初始H为空，initial_historical=0。重复跨事件不清零，保留首次信用event_id与目标最初发布时间来源。发布/起点的零移动信用另列；90/180转弯沿真实向量跨计划、跨等待计数。成功若D非空只表示当前可检完成返航。

独立auditor不导入executor/contracts，不调用主更新函数：用事件前缀集合、自己的层次BFS、方向标签及逐条move/wait重建所有输入/信用/计划游标/M/E，再核对事前手算期待账。只读verify会重新做普通BFS，打印实际次数；它不调用stub或规划器，不再跑模拟闭环。所有主BFS、独立审核BFS和核验BFS分账，A*/Dijkstra/覆盖精确均0。

fixture_spec的12类含23子例、25模拟会话；图/路线/预期均在首次执行前保存并hash封存。不能以实现输出反填期待值；不修改旧包、冻结源码或留出，不提交推送。完成封存即停止，真实小批另需执行稿。
