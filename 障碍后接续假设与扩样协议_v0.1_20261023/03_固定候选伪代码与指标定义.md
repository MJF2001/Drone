# 一次恢复目标干预：固定候选及指标口径

本文件是伪代码和定义，不是可运行实现或已完成验收。只允许一个备选、一处替换。所有“当前pending”都是本次规划前缀的预测集合，与事件快照的物理H分开。

## 1. 候选与触发

设E快照初始任务U0=T_E−H，原生逐格执行到当前预测位置c时，pending按原版逐格删除；来向previous取真实给定来向或当前预测路径前驱。A_old是02保存的旧计划锚点序列，原始次序不按新距离重排。

```text
used_or_examined = false
在每次原版决策时：
    options = 原版reward_options(c, previous, pending, F_E, predator, (2,.5))
    若options非空：照原版choose_neighbor，不调用选择干预
    否则若pending非空：
        q0 = min(pending, key=(原几何g.distance(c,q), q.x, q.y))  # 原语句保留
        chosen = q0
        若not used_or_examined 且len(pending) >= 2：
            used_or_examined = true  # 即使缺候选也不能移到下次恢复
            q1 = A_old里首个满足q属于pending且q != q0的point
            若不存在：记录no_distinct_old_candidate
            否则：
                核对q1属于F_E、未采、旧序列身份与当前可达性
                若不满足：记录candidate_unavailable；不取下一个q
                否则：
                    记录完整身份(current,previous,pending,trace序号,path index,q0,q1)
                    d0=g.distance(c,q0), d1=g.distance(c,q1)  # 同一原对象
                    若enabled：chosen=q1；替换次数加1
        segment = 原几何g.path(c,chosen)  # 路径平局/缓存语义不改
        原版逐格move(segment,pending)，沿途采集全部保留
    此后仍按原版决策，已考察标志不复位
pending为空后：照原版返航并完整审核
```

去重规则是A_old按旧原生index递增、每point仅第一次；默认最短距离平局仍按坐标(x,y)升序，备选平局只服从旧次序。只允许一个q1，不以d1、任务邻居数或完整结果筛选它。q1可能同距或更远，均保留；若d1<d0，属于默认/距离合同错误，不算H1改善。初始U均可达不代表可以省略当前候选可用性留证；发生矛盾先记错误，不能偷偷跳到下一个候选。

若第一次恢复仅1个pending，此后不会重新增多，没有适用触发；与“全程无恢复”分开记。选择器不接收P2、未来事件、新算N、完整替代路线、完整距离或末采格。

REF保持冻结核心，完成后在同一20秒窗口用受限扫描器顺序重建原生前缀和pending；只输出上述第一次触发及q1，不求d1、不看未来后缀与结果长度。扫描器的调用参数必须是前缀流和旧A_old，不能把完整结果对象交给候选择器。实现时保存这个参数边界的验收。REF扫描超时则该状态不进入OFF/ALT。

OFF/ALT1用最小隔离钩子在同一个原几何对象内计算候选及d0/d1。OFF也执行候选逻辑，仅不替换；ALT1不能引用OFF未来路线来找机会。两臂触发前的原生前缀、pending、来向和默认身份必须一致。与REF的等价只排除新增诊断元数据、运行秒数和查询缓存统计，不能排除原有目标、决策类型、原生路径或信用差异。

继承已验`覆盖受阻恢复目标单变量诊断_v0.1_20261023`的隔离、一次例外和独立逐决策审核方式；未来适配须保存diff及源码哈希，不覆盖该旧包。不得直接沿用其手填trace编号或两个Z的目标。

## 2. H1主指标与结果类别

所有差取ALT1减OFF，负距离代表更短；无效或缺失项为null并给原因，不用0替代。

| 指标 | 定义与单位 | 能否用于选择候选 |
|---|---|---|
| d0、d1、Δd | 同一触发c至默认/备选目标的原几何最短四邻接距离；Δd=d1−d0，格长单位 | 只记录，不筛选 |
| Lraw、Δraw | 完整原生路线单位边数，包括最后采集后的返航 | 否，事后 |
| Lpost、Δpost | 同版合法直达完整折线的欧氏长度；Δpost为主量 | 否，事后 |
| Δ% | 100×Δpost/Lpost(OFF)，OFF为0时未定义 | 否 |
| A(q) | 在触发时，pending内与q四邻接的目标数，0..4；A(q0)、A(q1)及其差 | 决策时可算；本批仅记录，不作为评分/门槛 |
| old_rank(q) | q在已冻结A_old中的原始序号；q0不在序列记null | 决策时可算；仅记录 |

浮点只展示，严格正/负/等长用原生整数与公共直达根式/有理区间证书判定；独立Fraction/isqrt核验差式及符号，不引入浮点epsilon挑正例。若有限审核预算内符号不能认证，记numeric_unresolved，不按显示小数判胜负。纯原生等路必须逐点比对，直达等路也逐点核对并检查信用，不能只比长度。

固定结果类别按如下先后判定：

1. 历史/切点/障碍不合格：不适用，保留12槽分母。
2. REF失败、迟到、无恢复、恢复仅余1目标、无不同旧候选、候选不可用：分别登记，不冒充零收益。
3. OFF不等价或任何语义/审核错误：未解决错误；停止本批后续真实入口，保留已跑槽。
4. ALT未运行、失败、迟到、预算/边数不合格、数值未解决：分别登记，不能挤进有效距离配对。
5. 原生与直达物理路线均相同：目标标签不同但同路零效应，即便trace条数和恢复分账不同。
6. 原生相同但直达不同：先检查软截止/候选上限/公共处理差异；不作目标选择的严格H1证据。
7. 路线不同、Δpost=0：等长不同路；Δpost<0为更短，>0为更长。每类再分Δd=0、>0。Δd<0属于错误。

记录直达fallback/candidate_cap/soft_deadline。及时且合同有效的fallback结果可以保留为预算下输出；严格H1门槛只计OFF/ALT1均自然完成且fallback为null的配对，任一臂触顶均排除于严格门槛并单列，不事后判断“是否依赖截止”。普通精度或时钟噪声不能代替目标效应。

## 3. H2：固定的逐例轨迹见证

先取两条完整原生路径的最长共同前缀；p为该前缀最后顶点，u0/u1为两臂各自下一顶点，Q*为U0扣除共同前缀已采目标。保存共同前缀索引、p、真实入向、u0/u1、Q*及其哈希，不能从目标标签推断路径已经分歧。

若原生路径相同，H2没有物理分歧；若一条路径恰是另一条前缀、某臂失败或缺下一步，按terminal_prefix/unknown登记，不补造下一步。初始分歧无共同入边时用快照真实previous，仍缺失则转向角未知。

固定遗留集合：`L=(Adj4(p)∩Q*)−{u0}`。默认下一步没有服务的、就在该决策点四邻域内的未采目标才纳入；对两臂使用同一个L。u1是否属于L单列。L为空就记该狭义定义不适用，不把半径扩成2、不寻找另一个有利分歧点，也不人为分任务块。

对每个q∈L，固定邻域 `Z(q)={z:||z−q||1≤1}`，包含q及四邻格。沿每臂从分歧p开始，到q第一次原生中心服务为止，找所有完整的离开—重新接近片段：

- 路径索引i−1仍在Z(q)，i在Z(q)外，q在离开时尚未服务；
- j为离开后第一次重新进入Z(q)的索引，i..j−1均在外，且j不晚于q的第一次中心服务；
- 保存含两端的路径片段[i−1,j]，长度为j−i+1个单位边，记录该段实际新增信用、离开/重入点及q服务索引。重入不等于q已服务。

把这些片段覆盖的**边索引集合取并集**，其大小记W。每条路线各自计W，两臂使用同一L；同一边被多个q见证不重复相加。它是“对固定遗留任务重新接近的见证行程”，不是可删除绕行量，不保证是最短连接，也不与阶段成本相加作独立贡献。任务未完成/截断没有闭合片段时记unknown，不把截断片段当0。

同时保存p处入向与u0/u1夹角、两臂被干预恢复的起终索引、p是否恰为默认恢复结束点、默认下一决策是否local。这样可以区分恢复连接中分歧、恢复后转向和更晚分歧，不能统称“恢复后过早转向”。恢复途中偶然服务也照记。

本批H2只逐例判定，不输出推广支持率：

| 类别 | 事前口径 |
|---|---|
| 与狭义机制相容 | p恰为默认恢复结束点，默认接着local并有非零实际转向；L非空且默认确有q未采时离开后重入的保存见证；ALT对同L减少W、减少恢复结束后的原生覆盖行程，且Δpost<0。只能说与解释相容，不能宣称W减少的独立因果贡献。 |
| 本例解释不相容/反向证据 | H1虽改善，但同L没有减少该见证，且费用只在返航或直达层改善，则这一狭义往返解释未得到本例支持；或W减少却完整路线更长，反对把W直接当有益评分。此类反对本例解释/规则化，不证明所有场景不存在H2。 |
| 未确定 | L为空、缺少恢复后转向条件、第一分歧在其他阶段、信用/数值未解、失败或证据不能排除竞争解释等。保留轨迹，不通过改变定义补证。 |

“少走回头路”不能凭图判断；必要通行、重复格或无新增信用移动都可能包含在W中。即使相容，也不把中性“在此转向”改写成已证明“过早转向”。

## 4. 小型手算例子（仅核对定义）

例1：p=(0,0)，L={q=(1,0)}，Z(q)={(1,0),(0,0),(2,0),(1,1),(1,−1)}。给定固定折线
`(0,0)→(−1,0)→(−1,1)→(0,1)→(1,1)→(1,0)`。
它在i=1离开，j=4首次重入，q在索引5才服务；见证片段[0,4]长4，不能把后续服务那一边也计入此闭合片段。给定另一条折线`p→q`，W=0。这里只检查已写定点串的单位邻接与集合成员，没有生成任何地图的反事实路线；这两条小串也没有构成完整责任相同的H1实验。

例2：两个任务的见证边索引分别{0,1,2,3}与{2,3,4}，并集W=5，不是7。q若已在共同前缀采完，则不在Q*，不进入L。若路径相同但目标不同，物理同路零效应；若q未完成，缺失值不记W=0。

例3：手给Δd=+1、Δraw=−2、Δpost=−1，可作为H1符号定义的正例；Δd=0、Δpost<0仅属等距改善；Δd>0、Δpost>0是退化。上述只是数字定义例，非本批结果。

## 5. 返航、直达与完整成本账

原生分四段保存单位边数：触发前、被选目标恢复段、该恢复结束至最后原生服务、最后服务至基地；四段必须精确加回Lraw。记录恢复段中实际服务，所有边只计一次。若两臂物理同路但目标终点不同，分账只是边界重分，不从分账差编机制故事。

记录原生末采格、原生返航长度；公共直达另存实际信用顺序、首末见证位置、直达末信用至基地的费用。直达信用是已验的有理内部见证口径，见证中点不是唯一物理首次入区时刻。沿用首见证前/首末之间/末见证后分账并核总和，不把原生恢复/覆盖/返航三段硬移植到任意方向连接。

H3的一个强费用标志：Δraw<0，而Δ(原生返航前所有行程)≥0、Δreturn<0，说明原生净改善依赖返航降低；即使W存在也不能说全部收益来自往返。覆盖和返航都改善时并列，不设任意“主要占比”阈值。目标终点变化本身也不是独立机制因果证明。

令G=Lpost−Lraw，ΔG=Δpost−Δraw。H4强费用标志为Δpost<0且Δraw≥0：公共处理的几何变化提供了净改善；若两者都改善则分别列数，不强制唯一归因。原生同路而post仅因软截止不同不能直接归为目标的几何收益。

每臂保留完整责任/暂缓集合/物理H/实际信用/未完成任务/基地终点/资源上界、安全与独立审核、各状态错误和迟到。转弯记录非零次数、90°/180°/其他、累计角度，原生与直达分列。

计时从输入解析、候选选择、核心、包装、公共直达、保存编码、主内核验到处理返回完整记录；主外独立审核另列，并给两者合计诊断成本。记录原生核心详细profile为OFF/null，不把未知计为零；选择器自有计数、资格BFS及独立审核计数照账。单seed只做确定性距离诊断，时间只描述本机本批观测，不能与旧批精确比较速度，也不是独立重复的统计时间实验。
