# 建议草案：相对小片留后，其他片区优先

**本稿是唯一推荐设计，全部新增定义均为“建议，待核定”。尚未实现，未对旧案例计算是否触发，更未运行实验。** 用户确认的是研究假设；以下划片、少量、位置条件和持续优先级没有得到用户核定。上一轮成本审查已经完成，其未实施计时建议本轮不推进；失败的16/64估计器继续关闭。

推荐采用**持续的两阶段优先级**：条件满足时，先把其他片区作为自主选择目标的范围；其他片区的任务全部完成后，再释放留后片。其他片区之间仍按原PPCPP选择，不另排一个完整片区排列。

这比“只换一次目标”强：它同时影响后续紧邻目标和恢复目标选择，不能称为一次干预。它也不保证真正最后采到留后片——若必经它而提前采完，或者整条直达提前取得信用，必须照记，并报告“留后未成立”。

## 四个定义

|问题|唯一建议|限制|
|---|---|---|
|分离片区|沿用事件前已登记的矩形任务标签。只考虑至少两个仍有责任的标签；这些标签的原任务格集合互不重叠，且不同标签间没有四邻接任务格。|是预给任务分区，不是自动道路分区；飞行域可以完全连通。已采格、障碍把一个标签内的pending割开也不拆标签；空片停用，标签不合并。相接/重叠/漏归属时不启用。|
|少量|在当前非空片区中，存在**唯一严格最少任务数**的片S。任务数在规则检查时从原生完整pending计。|只定义“相对最少”，没有绝对数量或百分比阈值。49对50也会被叫作相对最少，这是明确局限。若负责人要求绝对少量，须另裁决；本稿不私加比例或根据I的1/32反推阈值。最少数并列则不干预。|
|适合返航衔接|每片取“当前pending中到基地合法格路距离最短的格心”为代表r_i，同距按坐标。对每一其他片R，都要求：①r_S在r_R至基地的一条最短连接上；②经r_S再去r_R，比当前位置直接去r_R严格更远。|同时检查当前点、其他片、基地及公开障碍，不只看离基地近。代表格不是该片真实出口/末采点；局部格路条件不保证完整覆盖更短，也不保证直达后仍有收益。|
|不干预|分区/责任/距离资料不满足；只有一片；最少数并列；位置条件不明确；原默认恢复目标已在其他片；默认与规则目标同片；基本资源/合法输入合同不满足。|回退指原规则继续规划，不能凭空借用一条尚未生成的默认完整路线。截止已到或最终路线资源不合法属于失败，不假报成功回退。|

位置条件用当前公开四邻接图的精确整数距离d，具体为所有R≠S同时满足：

```text
d(r_R,B) = d(r_R,r_S) + d(r_S,B)
d(X,r_R) < d(X,r_S) + d(r_S,r_R)
```

第一条是代表格“回基地顺路”；第二条排除“从当前点去其他片本就要先经过代表格”的情形。任何一片不满足，都不启用；不挑一个最有利的R。条件是局部连接关系，**不是给两条完整覆盖路线估总长再择优**。本轮没有计算这些距离或对19旧例跑判据。

## 一张流程

```text
新增障碍事件；保留真实H和完整任务责任
       ↓
按原PPCPP规划，到本事件第一次原生恢复选择
       ↓ 只检查这一次，不在后面寻找有利机会
片区合法分离？唯一相对小片？代表格位置条件成立？
原默认目标在S，排除S后的原最近目标确实在另一片？
       ├─ 否 → 本事件其后全部原规则
       └─ 是 → OTHER：不主动选S，其他片之间沿用原选择
                        ↓ 每条移动边都照常采集，绝不把S变禁飞
                 其他片已采完 → TAIL：释放S，按原规则完成并返航
                 S沿途先采完 → 取消优先级，原规则完成其余任务
                 全部已采完 → 返航，不再人为访问S
```

“不主动选S”包括紧邻分支；只在恢复钩子里改一个目标不能实现此流程。它不禁止穿过S、不删任务、不改H/暂缓；公开障碍和F完全不改。原生预测pending与公共直达实际信用继续分别计算。

## 已知风险与可证伪点

- 保留的是整片目标选择优先级，片内仍可能多次进入/离开；没有“一次扫完每片”的假设。
- 即使三个代表格条件成立，另一片真实退出位置可能很远，跨区行程、片内顺序和转弯也可能变差。距离主指标必须是完整覆盖加返航。
- 采用合法格路而非欧氏距离避免明显穿障碍误判，但需要额外距离行，不能先称廉价或更快。
- 最少任务数不是充分条件；相对最少仍可能很多。试验安排数量变化、折返、单片保护与障碍绕行反例；不只复刻I。
- 当前小图证据中，同片也能改善、同块序也能退化。本方案只是主动缩小范围，不解决这些全部问题，也不能因未碰到旧T而宣布有效。
- 与LAST都有“留后”的机制重合；本方案不删除任务格的通行权、不完整试走选短。差别不足以证明创新，尚无确认主算法。
