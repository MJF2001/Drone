# 确定性伪代码与接口改动——全部建议，待核定

这是规范文本，不是可运行的规则模块。没有实现/测试下述状态机，也没有把它应用于旧输入。

## 输入和唯一准备时点

输入只含当前公开F/P、物理H、可检/暂缓账、事件起点/当前位置/真实来向、基地B、剩余距离资源、当前原生预测pending Q、共同已规划前缀和**事件前登记**的矩形任务标签P_i。P_i不是从候选路线、未来末采或收益重划。规则不用事件前旧锚点顺序补尾，也不用旧q1名单；旧计划只用于未来样本“确实受阻”的资格核查。

Q由当前可检任务减物理H、减本轮已规划原生逐格采集得到；它是原PPCPP唯一完整预测责任账。不能把留后片从Q、原Snapshot.targets或物理H中移走。被障碍遮挡但未采任务在原暂缓账，不得改成已完成。

在本事件**第一次原生恢复分支**，原默认q0已经按原合法距离和坐标平局得到时，只准备一次。没有恢复则不启用；该次条件不满足，本事件不在以后重试。不得遍历多个时点追求触发。

## 准备过程（抽象规范，不执行）

```text
PREPARE(X, previous, Q, q0, metadata, original_geometry, deadline):
    标记本事件已检查
    若输入合同不合法：保持原始失败语义；不得伪造有效回退
    若标签资料缺失，或有任务漏归属/重叠：DEFAULT_REST
    若非空片少于2：DEFAULT_REST
    若任意两个非空标签的原P_i存在四邻接任务格：DEFAULT_REST
    # 检查原标签间隔，不用当前Q的碎裂发明新片

    n_i := |Q ∩ P_i|
    若最小n_i不唯一：DEFAULT_REST
    S := 唯一最小片；保存S的检查时任务集合Q_S0
    若q0不属于S：DEFAULT_REST

    用当前F中的冻结距离接口求d；任一真实超时：TIMEOUT，不加时回退
    对每个非空片i：
        r_i := argmin_{q ∈ Q∩P_i} (d(B,q), q的坐标)
    对每个R≠S：
        若d(r_R,B) != d(r_R,r_S)+d(r_S,B)：DEFAULT_REST
        若d(X,r_R) >= d(X,r_S)+d(r_S,r_R)：DEFAULT_REST
    q_R := argmin_{q ∈ Q\P_S} (d(X,q), q的坐标)
    若q_R与q0同格/同标签：DEFAULT_REST
    激活 OTHER(S)；S和判据冻结，不随后续最少数变化重选S
```

q_R是本方案限制片区后的原最近恢复目标，不是旧OFF/ALT诊断的q1。未来它可能与旧q1不同，因此旧两臂完整结果不能冒充新规则结果。本稿没有生成这个新目标或路线。若目标同片则保持原规则；这里限定的是跨片优先级，未声称所有同片两目标都没有改进。

同距代表格/恢复目标都按原坐标字典序，不按块编号择利；最少数并列直接不启用。块标签固定，不自动拆分/合并：pending碎裂仍原标签，空标签停用，重叠/相接不归并凑数。新增事件到来使F/责任改变时，旧计划/优先级失效，按实际新H重新进入新事件合同；不预知未来、不在本轮自动扩为闭环。

## 运行状态和选择分支

状态为UNEXAMINED、DEFAULT_REST、OTHER(S)、TAIL(S)、RETURN、FAILED。除了首次恢复准备，原生主循环每次决策/每条移动边的处理如下：

```text
每条移动边：
    用原F和原连接规则飞行；照常更新完整Q中的实际经过格
    # 只是规划中的原生预测，不回写事件物理H
    若Q为空：下次进入原返航
    否则若state=OTHER且Q\P_S为空：记录release源顶点，state=TAIL
    否则若state=OTHER且Q∩P_S为空：记录提前采完，state=DEFAULT_REST
    已选定的合法连接继续到原端点，下一决策才选新目标

每次选择：
    若Q为空：原连接器返航；最终原生合法/覆盖/资源审核
    E := Q\P_S，当state=OTHER；否则E := Q
    若OTHER却E为空：先切TAIL，再令E=Q；不能误判全任务完成
    O := 原reward_options(current, previous, Q, F, 原捕食者/权重)
    O_allowed := 从O中删除cell不在E的项，保留原各项得分不重算
    若O_allowed非空：用原评分/坐标平局选紧邻格
    否则：用原合法距离/坐标平局在E中选恢复目标，原连接器展开
    # 即使O只有留后片目标，OTHER也会改走恢复；这是有意改动
```

因此该方案不是“片内一定整块扫完”。其他片之间仍会按原奖励/最近恢复穿行，允许交错；只约束自主目标选择时先清Q\P_S。原奖励在**完整Q**上计算后过滤，不能将E直接传作pending，否则边界项/距离归一化等也被暗改。既有PPCPP程序的循环、局部与恢复二分支都须独立适配，旧`Diagnostic.choose`单钩子不足以实现。

若沿途采完S，优先级取消；不禁止穿行，不拒绝信用，不再强访S。如果S只被采掉部分，仍按固定S保留剩余部分，不换另一个S。释放时Q_S仍为空并不是留后成功；最终所有Q为空时才返航。

## 回退、失败与资源

- **检查前/条件不成立：**DEFAULT_REST，从同一已规划前缀、原Q与来向继续原策略；原输入责任不变。
- **资料不足且还未激活：**不近似补欧氏距离，不猜分区，记不适用并原规则继续。可达性/地图前提本身失败则沿用环境失败，不说完成了回退路线。
- **激活后S提前采完：**只取消后续优先级；已规划路线不回滚，不能称整个结果与原版等价。
- **计算截止：**所有规则计算吃原核心共同预算，截止到达就失败；没有“再给原版一段时间”。代码异常/状态不一致不能伪装普通不适用。
- **资源：**启用前须有合法有限资源、原可达预检且至少可合法返航；这些不是完整覆盖资源证明。最终完整原生长度超额度或post不合法则该方法失败，记录，不借主对照已生成路线免费补救。没有额外保底完整试走，不保证优先级可行且更短。
